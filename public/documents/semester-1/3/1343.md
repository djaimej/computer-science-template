## 4.3 Listas simples.

---

### 1. Definición y Conceptos Clave

#### 1.1 Lista Simple

Estructura lineal que almacena elementos secuencialmente, donde cada nodo contiene:

- **Dato**: Valor almacenado
- **Enlace**: Referencia al siguiente nodo

$$ \text{Lista} = \langle \text{Nodo}_1 \rightarrow \text{Nodo}_2 \rightarrow \cdots \rightarrow \text{Nodo}_n \rangle $$

#### 1.2 Complejidad Temporal

| Operación | Complejidad                     |
| --------- | ------------------------------- |
| Inserción | $O(1)$ (cabeza) / $O(n)$ (cola) |
| Búsqueda  | $O(n)$                          |

### 2. Implementación Básica

#### 2.1 Clase Nodo

```java
public class Nodo<T> {
    T dato;
    Nodo<T> siguiente;

    public Nodo(T dato) {
        this.dato = dato;
        this.siguiente = null;
    }
}
```

#### 2.2 Clase Lista

```typescript
class ListaSimple<T> {
  private cabeza: Nodo<T> | null;

  constructor() {
    this.cabeza = null;
  }

  agregarAlInicio(dato: T): void {
    const nuevoNodo = new Nodo(dato);
    nuevoNodo.siguiente = this.cabeza;
    this.cabeza = nuevoNodo;
  }
}
```

### 4. Operaciones Principales

#### 4.1 Inserción

```mermaid
flowchart LR
  NN["Nuevo Nodo"] --> LV{"Lista vacía?"} -- Si --> CN["Cabeza = Nuevo"]
  LV -- No --> SC["Nuevo.siguiente = Cabeza"] --> CN
```

#### 4.2 Búsqueda

```python
def buscar(self, valor):
    actual = self.cabeza
    while actual:
        if actual.dato == valor:
            return True
        actual = actual.siguiente
    return False
```
