# Estructuras de Datos - Árboles binarios de búsqueda

## 11.3 Aplicaciones.

---

### 1. Introducción

Un **Árbol Binario de Búsqueda (BST)** es una estructura de datos jerárquica que permite organizar elementos de manera que:

- Para cada nodo, los valores del subárbol izquierdo son menores.
- Los valores del subárbol derecho son mayores.

Esto facilita operaciones como **búsqueda, inserción y eliminación**, y tiene aplicaciones en múltiples áreas de la informática.

### 2. Aplicaciones principales

#### 2.1 Búsqueda eficiente

- Los BST permiten búsquedas promedio en $O(\log n)$.
- Útiles para bases de datos pequeñas y almacenamiento dinámico.

**Ejemplo en Python:**

```python
class NodoBST:
    def __init__(self, valor):
        self.valor = valor
        self.izquierdo = None
        self.derecho = None

# Función de búsqueda
def buscar(nodo, valor):
    if not nodo or nodo.valor == valor:
        return nodo
    if valor < nodo.valor:
        return buscar(nodo.izquierdo, valor)
    else:
        return buscar(nodo.derecho, valor)
```

#### 2.2 Conjuntos y diccionarios ordenados

- Las bibliotecas implementan conjuntos y mapas **ordenados** con ABB balanceados: `TreeMap` y `TreeSet` en Java o `std::map` en C++ usan árboles rojinegros.
- Además de buscar, permiten consultas que una tabla hash no resuelve eficientemente: mínimo y máximo, sucesor y predecesor, y **consultas de rango**, como todos los valores entre $a$ y $b$, en $O(\log n + k)$ para $k$ resultados.
- Recorrer el árbol en inorden da los elementos ordenados: insertar $n$ valores y recorrerlos es un método de ordenamiento, *tree sort*, de costo $O(n \log n)$ si el árbol se mantiene balanceado.

#### Otras estructuras arbóreas relacionadas

Las secciones siguientes describen árboles que **no son árboles de búsqueda**: comparten la estructura de árbol, pero no la propiedad de orden de un ABB. Se incluyen para contrastarlos.

#### 2.3 Árboles de Expresión

- Representan expresiones matemáticas o lógicas.
- Nodos internos: operadores
- Hojas: operandos
- Utilizados en **compiladores y evaluadores de expresiones**.

**Ejemplo en Python:**

```python
class NodoExp:
    def __init__(self, valor, izquierdo=None, derecho=None):
        self.valor = valor
        self.izquierdo = izquierdo
        self.derecho = derecho

def evaluar(nodo):
    if not nodo.izquierdo and not nodo.derecho:
        return nodo.valor
    izq = evaluar(nodo.izquierdo)
    der = evaluar(nodo.derecho)
    if nodo.valor == '+':
        return izq + der
    elif nodo.valor == '*':
        return izq * der

raiz = NodoExp('+', NodoExp('*', NodoExp(3), NodoExp(5)), NodoExp(2))
print(evaluar(raiz))  # 17
```

#### 2.4 Árboles de Decisión

- Usados en **IA y machine learning**.
- Cada nodo representa una condición, con ramas para posibles decisiones.

**Diagrama Mermaid:**

```mermaid

    a["¿Edad > 30?"] --> c["No"]

    e --> g["Comprar"]

```

#### 2.5 Heaps

- **Heaps binarios:** implementan **colas de prioridad**. Solo exigen que cada nodo sea mayor, o menor, que sus hijos, así que no permiten buscar un valor arbitrario en $O(\log n)$.
- Operaciones: inserción y extracción de máximo/mínimo en $O(\log n)$.

**Ejemplo Python:**

```python
import heapq
heap = []
heapq.heappush(heap, 5)
heapq.heappush(heap, 2)
heapq.heappush(heap, 8)
print(heapq.heappop(heap))  # 2
```

#### 2.6 Bases de Datos y Sistemas de Archivos

- **B-Trees y B+ Trees:** generalizan los ABB a nodos con muchas claves y muchos hijos; se usan para indexar grandes volúmenes de datos en disco.
- **Sistemas de archivos:** estructuras de directorios jerárquicos.

**Diagrama Mermaid (directorio):**

```mermaid

    Carpeta1 --> Archivo2

```

### 3. Conclusiones

- Los BST son la base de los conjuntos y diccionarios ordenados, de las consultas de rango y de los índices de bases de datos; otros árboles, como los de expresión, de decisión y los heaps, resuelven problemas distintos.
- La eficiencia depende del **balance del árbol**.
- Se pueden combinar con estructuras avanzadas (AVL, Red-Black, B-Trees) para mejorar rendimiento.
