# Introducción a las Ciencias de la Computación - Objetos, estados y servicios

## 3.1 Variables locales y atributos. Niveles de visibilidad.

---

### 1. Definiciones Clave

#### 1.1 Atributos (Variables de Instancia)

- **Definición:** Variables declaradas en una clase que definen el estado de un objeto
- **Vida:** Persisten mientras exista el objeto
- **Alcance:** Accesibles en todos los métodos de la clase

$$ \text{Estado} = \sum_{\text{atributos}} \text{valores actuales} $$

#### 1.2 Variables Locales

- **Definición:** Variables declaradas dentro de un método o bloque
- **Vida:** Existen solo durante la ejecución del método
- **Alcance:** Solo dentro del bloque donde se declaran

### 2. Comparación

| Característica     | Atributos                    | Variables Locales         |
| ------------------ | ---------------------------- | ------------------------- |
| **Declaración**    | En la clase                  | En métodos/bloques        |
| **Inicialización** | Automática (valores default) | Obligatoria antes de usar |
| **Acceso**         | Desde cualquier método       | Solo en su bloque         |

##### Explicación:

- **private (`-`)**: Solo accesible en la misma clase
- **protected (`#`)**: Accesible en la clase y subclases
- **public (`+`)**: Accesible desde cualquier clase
- **package (`~`)**: Accesible en el mismo paquete

#### 3.2 Ejemplo en Java

```java
public class CuentaBancaria {
    private double saldo;  // Atributo privado

    public void depositar(double monto) {
        double comision = 0.05;  // Variable local
        saldo += monto - (monto * comision);
    }
}
```

### 4. Buenas Prácticas

#### 4.1 Regla de Ocultamiento

$$ \text{Encapsulamiento} \approx \frac{\text{Atributos privados}}{\text{Atributos totales}} $$

#### 4.2 Consejos

1. Usar `private` para atributos por defecto
2. Variables locales deben tener el menor alcance posible
3. Evitar atributos públicos (excepto constantes `final`)
