## 1.1 Programación imperativa.

---

La **programación imperativa** es un paradigma de programación que describe la computación en términos de instrucciones que cambian el estado de un programa. Se centra en **cómo** se realiza una tarea, paso a paso.

#### Características Principales

- **Secuencialidad**: Las instrucciones se ejecutan en orden
- **Estado mutable**: Uso de variables que pueden cambiar de valor
- **Efectos secundarios**: Las funciones pueden modificar estado externo
- **Estructuras de control**: Bucles, condicionales y bifurcaciones

El paradigma refleja directamente la **arquitectura de von Neumann**: una memoria que guarda datos e instrucciones, y un procesador que ejecuta instrucciones una tras otra leyendo y escribiendo esa memoria. Las variables son nombres para celdas de memoria y la asignación es la operación básica. Lenguajes como Fortran, C, Pascal y el ensamblador son imperativos; Python, Java o C++ son multiparadigma, pero su núcleo también lo es.

### Conceptos Fundamentales

#### Variables y Asignación

```python
# Asignación imperativa
x = 5          # Asignación inicial
x = x + 1      # Modificación del estado
print(x)       # Output: 6
```

#### Estructuras de Control

##### Condicionales

```python
# Estructura if-else
edad = 18
if edad >= 18:
    print("Mayor de edad")
else:
    print("Menor de edad")
```

##### Bucles

```python
# Bucle for
for i in range(5):
    print(f"Iteración: {i}")

# Bucle while
contador = 0
while contador < 5:
    print(contador)
    contador += 1
```

### Modelo Matemático de Ejecución Imperativa

El estado de un programa imperativo puede representarse como:

$$
\sigma = \{x_1 \mapsto v_1, x_2 \mapsto v_2, \dots, x_n \mapsto v_n\}
$$

Donde:

- $\sigma$ es el estado del programa
- $x_i$ son las variables
- $v_i$ son los valores actuales

La ejecución de una instrucción transforma el estado:

$$
\langle S, \sigma \rangle \rightarrow \sigma'
$$

Por ejemplo, la asignación evalúa la expresión en el estado actual y actualiza una sola variable:

$$
\langle x := e, \sigma \rangle \rightarrow \sigma[x \mapsto \sigma(e)]
$$

Si $\sigma = \{x \mapsto 5\},$ la instrucción `x = x + 1` produce $\sigma' = \{x \mapsto 6\}.$ La secuencia $S_1; S_2$ ejecuta $S_1$ y luego $S_2$ sobre el estado resultante. Esta forma de describir el significado de un programa se llama **semántica operacional**.

### Ejemplos de Código

#### Ejemplo 1: Cálculo de Factorial

```python
def factorial(n):
    resultado = 1
    for i in range(1, n + 1):
        resultado *= i
    return resultado

# Ejemplo de uso
print(f"5! = {factorial(5)}")  # Output: 120
```

#### Ejemplo 2: Manipulación de Arrays

```python
# Programa imperativo para procesar una lista
numeros = [1, 2, 3, 4, 5]
cuadrados = []

for num in numeros:
    cuadrado = num ** 2
    cuadrados.append(cuadrado)

print(f"Cuadrados: {cuadrados}")
```

#### Ejemplo 3: Gestión de Estado

```python
class Contador:
    def __init__(self):
        self.valor = 0

    def incrementar(self):
        self.valor += 1

    def decrementar(self):
        self.valor -= 1

# Uso del contador
contador = Contador()
contador.incrementar()
contador.incrementar()
print(f"Valor actual: {contador.valor}")
```

### Comparación con Otros Paradigmas

#### Programación Imperativa vs. Declarativa

| Aspecto  | Imperativa       | Declarativa          |
| -------- | ---------------- | -------------------- |
| Enfoque  | **Cómo** hacerlo | **Qué** hacer        |
| Estado   | Mutable          | Inmutable            |
| Flujo    | Explícito        | Implícito            |
| Ejemplos | C, Pascal, Fortran (y el núcleo de Python o Java) | SQL, Haskell, Prolog |

El mismo cálculo en ambos estilos, en Python:

```python
numeros = [3, 8, 1, 9, 4]

# Imperativo: se indica paso a paso cómo recorrer la lista y actualizar el estado
mayor = numeros[0]
for n in numeros[1:]:
    if n > mayor:
        mayor = n
print(mayor)             # 9

# Declarativo: se indica qué se quiere, el máximo, y el lenguaje decide cómo
print(max(numeros))      # 9
```

#### Ejercicio 3: Calculadora de Estadísticas

Escribe un programa que calcule:

- Media: $\mu = \frac{1}{n}\sum_{i=1}^{n} x_i$
- Varianza: $\sigma^2 = \frac{1}{n}\sum_{i=1}^{n} (x_i - \mu)^2$
- Desviación estándar: $\sigma = \sqrt{\sigma^2}$

#### Soluciones

```python
# Ejercicio 1: en cada pasada el mayor elemento restante "burbujea" hasta el final
def bubble_sort(lista):
    n = len(lista)
    for i in range(n - 1):
        hubo_intercambio = False
        for j in range(n - 1 - i):
            if lista[j] > lista[j + 1]:
                lista[j], lista[j + 1] = lista[j + 1], lista[j]
                hubo_intercambio = True
        if not hubo_intercambio:      # ya está ordenada
            break
    return lista

print(bubble_sort([64, 34, 25, 12, 22, 11, 90]))   # [11, 12, 22, 25, 34, 64, 90]

# Ejercicio 2
class CuentaBancaria:
    def __init__(self, saldo_inicial=0):
        self.saldo = saldo_inicial

    def depositar(self, monto):
        if monto <= 0:
            raise ValueError("El monto debe ser positivo")
        self.saldo += monto

    def retirar(self, monto):
        if monto <= 0 or monto > self.saldo:
            raise ValueError("Monto inválido o saldo insuficiente")
        self.saldo -= monto

    def consultar_saldo(self):
        return self.saldo

cuenta = CuentaBancaria(100)
cuenta.depositar(50)
cuenta.retirar(30)
print(cuenta.consultar_saldo())   # 120

# Ejercicio 3
def estadisticas(datos):
    n = len(datos)
    suma = 0
    for x in datos:
        suma += x
    media = suma / n
    acumulado = 0
    for x in datos:
        acumulado += (x - media) ** 2
    varianza = acumulado / n
    return media, varianza, varianza ** 0.5

print(estadisticas([2, 4, 4, 4, 5, 5, 7, 9]))   # (5.0, 4.0, 2.0)
```

### Patrones Comunes en Programación Imperativa

#### Patrón 1: Acumulador

```python
def suma_acumulativa(numeros):
    acumulador = 0
    resultados = []

    for num in numeros:
        acumulador += num
        resultados.append(acumulador)

    return resultados
```

#### Patrón 2: Transformación con Estado

```python
def procesar_con_estado(datos):
    estado = {}  # Diccionario para mantener estado

    for item in datos:
        if item not in estado:
            estado[item] = 0
        estado[item] += 1
        # Procesamiento adicional

    return estado
```

### Análisis de Complejidad

#### Notación Big O para Operaciones Imperativas

| Operación      | Complejidad | Ejemplo             |
| -------------- | ----------- | ------------------- |
| Asignación     | $O(1)$      | `x = 5`             |
| Acceso a array | $O(1)$      | `arr[i]`            |
| Bucle simple   | $O(n)$      | `for i in range(n)` |
| Bucle anidado  | $O(n^2)$    | Dos bucles anidados |
