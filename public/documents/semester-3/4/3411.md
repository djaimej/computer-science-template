# Probabilidad I - Espacio de Probabilidad

## 1.1 Espacio muestral, eventos y su interpretación.

---

### 1. Introducción

La probabilidad es la rama de las matemáticas que estudia los fenómenos aleatorios. El **espacio de probabilidad** constituye la base formal sobre la cual se definen los eventos y sus probabilidades.

En este subtema, se estudian tres conceptos fundamentales:

1. **Espacio muestral**, denotado $\Omega:$ el conjunto de todos los resultados posibles de un experimento aleatorio.
2. **Eventos**, denotados $A, B, C, \dots:$ subconjuntos del espacio muestral.
3. **Interpretación probabilística**: cómo asignamos valores de probabilidad a los eventos y cómo se interpretan en la práctica.

### 2. Definiciones Fundamentales

#### 2.1 Experimento aleatorio

Un **experimento aleatorio** es aquel cuyo resultado no puede predecirse con certeza antes de realizarlo, aunque se conocen todos los posibles resultados.

Ejemplo: lanzar un dado, lanzar una moneda, medir la altura de una persona.

#### 2.2 Espacio muestral $(\Omega)$

El **espacio muestral** es el conjunto de todos los posibles resultados de un experimento aleatorio.

$$ \Omega = \{ \omega_1, \omega_2, \dots, \omega_n \} $$

cuando es finito. Ejemplos:

- Moneda: $\Omega = \{C, S\}$
- Dado: $\Omega = \{1,2,3,4,5,6\}$
- Lanzar dos monedas: $\Omega = \{CC, CS, SC, SS\}$

El espacio muestral no siempre es finito:

- Lanzar una moneda **hasta** que salga cara: $\Omega = \{C, SC, SSC, SSSC, \dots\},$ infinito pero **numerable**; se puede identificar con $\{1, 2, 3, \dots\},$ el número de lanzamientos.
- Medir el tiempo de vida de un foco: $\Omega = [0, \infty),$ un conjunto **no numerable**.

Elegir $\Omega$ es parte del modelado: para dos monedas se podría usar también $\Omega' = \{0, 1, 2\},$ el número de caras. Ambos son válidos, pero en $\Omega$ los cuatro resultados son igualmente probables y en $\Omega'$ no, porque obtener una cara puede ocurrir de dos maneras.

#### 2.3 Evento $(A)$

Un **evento** es cualquier subconjunto del espacio muestral.

- **Evento elemental**: un único resultado $\{\omega_i\}.$
- **Evento compuesto**: conjunto de varios resultados.

Si $\Omega = \{1,2,3,4,5,6\}$ (dado), entonces:

- $A = \{2,4,6\}$ es el evento "sacar un número par".
- $B = \{1\}$ es el evento "sacar el 1".

Se dice que el evento $A$ **ocurre** si el resultado $\omega$ del experimento pertenece a $A.$ Si se lanza el dado y sale 4, ocurre $A$ y no ocurre $B.$ Con $n$ resultados posibles hay $2^n$ eventos, uno por cada subconjunto; el dado tiene $2^6 = 64.$

#### 2.4 Probabilidad de un evento

La probabilidad de un evento $A \subseteq \Omega$ está dada por:

$$ P(A) = \frac{|A|}{|\Omega|} $$

si $\Omega$ es finito y todos los resultados son **equiprobables**.

Ejemplo: en un dado, $P(\text{par}) = \frac{3}{6} = \frac{1}{2}.$ La definición general de probabilidad, que no supone resultados equiprobables, se estudia en el tema 1.3.

### 3. Operaciones con eventos

Los eventos se comportan como conjuntos.

- **Unión:** $A \cup B$ ocurre cuando ocurre $A$ o $B,$ o ambos.
- **Intersección:** $A \cap B$ ocurre cuando ocurren $A$ y $B$ a la vez.
- **Complemento:** $A^c = \Omega \setminus A$ ocurre cuando no ocurre $A.$
- **Diferencia:** $A \setminus B = A \cap B^c$ ocurre cuando ocurre $A$ pero no $B.$
- **Evento imposible:** $\emptyset,$ que nunca ocurre.
- **Evento seguro:** $\Omega,$ que siempre ocurre.

Dos eventos son **mutuamente excluyentes** (o ajenos) si $A \cap B = \emptyset:$ no pueden ocurrir a la vez. Una colección $A_1, \dots, A_k$ de eventos ajenos dos a dos cuya unión es $\Omega$ es una **partición** de $\Omega:$ en cada realización ocurre exactamente uno de ellos.

Las operaciones cumplen las leyes del álgebra de conjuntos; las más usadas en probabilidad son las **leyes de De Morgan**:

$$ (A \cup B)^c = A^c \cap B^c, \qquad (A \cap B)^c = A^c \cup B^c $$

La primera dice que no ocurra ninguno de los dos eventos es lo mismo que no ocurra $A$ y tampoco ocurra $B.$ Valen también para uniones e intersecciones de cualquier cantidad de eventos.

#### Relación entre eventos

Con $A = \{2, 4, 6\}$ (pares) y $B = \{1, 2, 3\}$ (menores que 4), cada resultado del dado cae en una de las cuatro regiones del diagrama de Venn:

| Región | Resultados |
| --- | --- |
| $A \cap B$ | $\{2\}$ |
| $A \setminus B$ | $\{4, 6\}$ |
| $B \setminus A$ | $\{1, 3\}$ |
| $(A \cup B)^c$ | $\{5\}$ |

Las cuatro regiones son ajenas y su unión es $\Omega:$ forman una partición. Por De Morgan, $(A \cup B)^c = A^c \cap B^c = \{1, 3, 5\} \cap \{4, 5, 6\} = \{5\}.$

### 4. Interpretaciones de la probabilidad

1. **Clásica (Laplace):** todos los resultados son equiprobables.
   Ejemplo: $P(A) = \frac{|A|}{|\Omega|}.$

2. **Frecuentista:** probabilidad como límite de frecuencias relativas:

   $$ P(A) = \lim_{n \to \infty} \frac{\# \text { de veces que ocurre } A}{n} $$

3. **Subjetiva:** probabilidad como medida de creencia personal (aplicada en estadística bayesiana).

### 5. Ejemplos

#### Ejemplo 1: Dado

Sea $\Omega = \{1,2,3,4,5,6\}.$

- Evento $A:$ sacar un número par = $\{2,4,6\}$
- Evento $B:$ sacar mayor que 4 = $\{5,6\}$
- Unión: $A \cup B = \{2,4,5,6\}$
- Intersección: $A \cap B = \{6\}$
- Complemento: $A^c = \{1,3,5\}$

Probabilidades:

- $P(A) = 3/6 = 1/2$
- $P(B) = 2/6 = 1/3$
- $P(A \cap B) = 1/6$

#### Ejemplo 2: Lanzar dos monedas

$\Omega = \{CC, CS, SC, SS\}$

- Evento $A,$ obtener exactamente una cara: $A = \{CS, SC\}$
- Evento $B,$ obtener dos iguales: $B = \{CC, SS\}$

Entonces:

- $P(A) = 2/4 = 1/2$
- $P(B) = 2/4 = 1/2$
- $P(A \cap B) = 0,$ porque $A \cap B = \emptyset:$ son mutuamente excluyentes. De hecho $B = A^c,$ así que $\{A, B\}$ es una partición de $\Omega.$

### 6. Ejercicios Propuestos

1. Se lanza un dado:

   - Define $\Omega.$
   - Calcula $P(\text{número impar}).$
   - Calcula $P(\text{número mayor que 4}).$

2. Se lanzan dos monedas:

   - Escribe el espacio muestral.
   - Calcula la probabilidad de obtener al menos una cara.

3. De una baraja de 52 cartas:

   - Define el espacio muestral.
   - Calcula $P(\text{obtener una carta de corazones}).$
   - Calcula $P(\text{obtener un As}).$

### 7. Código de apoyo (Python)

```python
import itertools

# Espacio muestral de dos monedas, generado como producto cartesiano
Omega = {"".join(r) for r in itertools.product("CS", repeat=2)}   # {'CC', 'CS', 'SC', 'SS'}

# Eventos como conjuntos
A = {o for o in Omega if "C" in o}       # Al menos una cara
B = {o for o in Omega if o[0] == o[1]}   # Dos iguales

def P(evento):                           # resultados equiprobables
    return len(evento) / len(Omega)

print("P(A) =", P(A))                    # 0.75
print("P(B) =", P(B))                    # 0.5
print("P(A ∩ B) =", P(A & B))            # 0.25: solo CC
print("P(A ∪ B) =", P(A | B))            # 1.0
print("De Morgan:", Omega - (A | B) == (Omega - A) & (Omega - B))   # True
```

Representar los eventos con el tipo `set` de Python hace que las operaciones de conjuntos sean directamente `|` (unión), `&` (intersección) y `-` (diferencia).

### 8. Soluciones

**Ejercicio 1.** $\Omega = \{1, 2, 3, 4, 5, 6\}.$ Impar es $\{1, 3, 5\},$ así que $P = \frac{3}{6} = \frac{1}{2};$ mayor que 4 es $\{5, 6\},$ así que $P = \frac{2}{6} = \frac{1}{3}.$

**Ejercicio 2.** $\Omega = \{CC, CS, SC, SS\}.$ "Al menos una cara" es el complemento de $\{SS\},$ así que $P = 1 - \frac{1}{4} = \frac{3}{4}.$ Pasar al complemento es muy útil cuando "al menos uno" tiene muchos casos y "ninguno" tiene uno solo.

**Ejercicio 3.** $\Omega$ es el conjunto de las 52 cartas, por ejemplo pares $(v, p)$ con valor $v \in \{A, 2, \dots, 10, J, Q, K\}$ y palo $p \in \{\heartsuit, \diamondsuit, \clubsuit, \spadesuit\},$ y $|\Omega| = 13 \cdot 4 = 52.$ Hay 13 corazones: $P = \frac{13}{52} = \frac{1}{4}.$ Hay 4 ases: $P = \frac{4}{52} = \frac{1}{13}.$
