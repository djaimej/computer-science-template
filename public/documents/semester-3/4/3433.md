# Probabilidad I - Momentos de Variables Aleatorias

## 3.3 Esperanza de funciones de una variable aleatoria.

---

La **esperanza de funciones de variables aleatorias** es un concepto fundamental en probabilidad que extiende la noción de valor esperado. Nos permite calcular cantidades como $E[g(X)]$ donde $g$ es una función medible y $X$ es una variable aleatoria.

### 1. Definición formal

#### Para variables discretas

Si $X$ es una variable aleatoria discreta con función de masa de probabilidad $p(x),$ entonces:

$$E[g(X)] = \sum_{x} g(x) \cdot p(x)$$

#### Para variables continuas

Si $X$ es una variable aleatoria continua con función de densidad $f(x),$ entonces:

$$ E[g(X)] = \int_{-\infty}^{\infty} g(x) \cdot f(x) \, dx $$

siempre que la suma o la integral converjan absolutamente.

### 2. Propiedades fundamentales

#### Linealidad de la esperanza

Para cualesquiera constantes $a,$ $b$ y funciones $g,$ $h:$

$$E[a \cdot g(X) + b \cdot h(X)] = a \cdot E[g(X)] + b \cdot E[h(X)]$$

#### Monotonía

Si $g(x) \leq h(x)$ para todo valor $x$ que pueda tomar $X,$ entonces:

$$E[g(X)] \leq E[h(X)]$$

#### Valor absoluto

$$ |E[g(X)]| \leq E[|g(X)|] $$

que se sigue de la monotonía, porque $-|g(X)| \leq g(X) \leq |g(X)|.$

#### Advertencia: en general $E[g(X)] \neq g(E[X])$

La esperanza **solo** conmuta con funciones lineales. Si $X$ vale $-1$ o $1$ con probabilidad $\frac{1}{2}$ cada uno, entonces $E[X] = 0$ y $(E[X])^2 = 0,$ pero $E[X^2] = 1.$ La diferencia $E[X^2] - (E[X])^2$ es precisamente la varianza. Para funciones **convexas** siempre se cumple $E[g(X)] \geq g(E[X])$ (desigualdad de Jensen, tema 3.4).

### 3. Casos especiales importantes

#### Momentos de una variable aleatoria

$$ E[X^k] = \begin{cases} \sum x_i^k p(x_i) & \text{(discreta)} \\ \int x^k f(x) \, dx & \text{(continua)} \end{cases} $$

#### Función generadora de momentos

$$M_X(t) = E[e^{tX}]$$

#### Varianza como esperanza

$$\text{Var}(X) = E[(X - E[X])^2] = E[X^2] - (E[X])^2$$

### 4. Teorema fundamental (Ley del estadístico inconsciente)

No es necesario encontrar la distribución de $Y = g(X)$ para calcular $E[g(X)].$ Basta con conocer la distribución de $X:$

$$ E[g(X)] = \int_{-\infty}^{\infty} g(x) f_X(x) \, dx $$

Se le llama así porque muchos lo usan "sin darse cuenta" de que es un teorema y no la definición: por definición, $E[Y] = \sum_y y\,p_Y(y),$ que requiere la distribución de $Y.$

*Demostración en el caso discreto.* Agrupando los valores $x$ según el valor $y = g(x)$ que producen, y usando $p_Y(y) = \sum_{x : g(x) = y} p_X(x)$ (tema 2.5):

$$ \sum_x g(x)\,p_X(x) = \sum_y \sum_{x : g(x) = y} y\,p_X(x) = \sum_y y\,p_Y(y) = E[Y]. \qquad \blacksquare $$

En el caso continuo con $g$ monótona y derivable se demuestra con el cambio de variable $y = g(x)$ en la integral; el caso general requiere teoría de la medida.

### 5. Diagrama conceptual

```mermaid
flowchart TD
    A[Variable aleatoria X<br>con distribución conocida] --> B["Transformación Y = g(X)"]
    A --> C["Cálculo directo: suma o integral de g(x) por la distribución de X"]

    B --> D[Encontrar la distribución de Y]
    D --> F["Cálculo de E[Y] por definición"]

    C --> G["Mismo resultado: E[g(X)]"]
    F --> G
```

El camino de la izquierda, encontrar primero la distribución de $Y,$ suele ser mucho más largo; la ley del estadístico inconsciente permite tomar el de la derecha.

### 6. Ejemplos detallados

#### Ejemplo 1: Variable discreta
Sea $X$ una variable aleatoria con distribución $P(X = -1) = 0.2,$ $P(X = 0) = 0.5,$ $P(X = 2) = 0.3.$

Calcular $E[X^2]:$

$$ E[X^2] = (-1)^2 \cdot 0.2 + 0^2 \cdot 0.5 + 2^2 \cdot 0.3 = 0.2 + 0 + 1.2 = 1.4 $$

Por el camino largo: $Y = X^2$ vale 1 con probabilidad 0.2, 0 con probabilidad 0.5 y 4 con probabilidad 0.3, y $E[Y] = 0.2 + 1.2 = 1.4.$ Mientras tanto, $(E[X])^2 = (-0.2 + 0.6)^2 = 0.16 \neq 1.4.$

#### Ejemplo 2: Variable continua
Sea $X \sim \text{Uniforme}(0, 1)$ con $f(x) = 1$ para $0 \leq x \leq 1.$

Calcular $E[e^X]:$

$$ E[e^X] = \int_{0}^{1} e^x \cdot 1 \, dx = e^x \big|_{0}^{1} = e - 1 \approx 1.718 $$

mayor que $e^{E[X]} = e^{1/2} \approx 1.649,$ como predice Jensen, porque $e^x$ es convexa.

#### Ejemplo 3: Aplicación física
Si $X$ representa la posición de una partícula con densidad $f(x) = 2x$ para $0 \leq x \leq 1,$ la energía potencial es $U(X) = kX^2.$ Calcular la energía esperada:

$$ E[U(X)] = E[kX^2] = k \int_{0}^{1} x^2 \cdot 2x \, dx = 2k \int_{0}^{1} x^3 \, dx = 2k \cdot \frac{1}{4} = \frac{k}{2} $$

### 7. Implementación computacional

```python
import numpy as np
from scipy import integrate
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

def esperanza_funcion_discreta(valores, probabilidades, funcion):
    """Calcula E[g(X)] para variable discreta"""
    return sum(funcion(x) * p for x, p in zip(valores, probabilidades))

def esperanza_funcion_continua(funcion_densidad, funcion, lim_inf, lim_sup):
    """Calcula E[g(X)] para variable continua"""
    integrando = lambda x: funcion(x) * funcion_densidad(x)
    resultado, error = integrate.quad(integrando, lim_inf, lim_sup)
    return resultado

# Ejemplo 1: Variable discreta
valores = np.array([-1, 0, 2])
probabilidades = np.array([0.2, 0.5, 0.3])
funcion_cuadratica = lambda x: x**2

E_X2 = esperanza_funcion_discreta(valores, probabilidades, funcion_cuadratica)
print(f"E[X²] = {E_X2:.4f}")

# Ejemplo 2: Variable continua - Uniforme(0,1)
# np.where trabaja elemento por elemento; un "if" de Python no sirve con arreglos
f_uniforme = lambda x: np.where((0 <= x) & (x <= 1), 1.0, 0.0)
funcion_exponencial = lambda x: np.exp(x)

E_eX = esperanza_funcion_continua(f_uniforme, funcion_exponencial, 0, 1)
print(f"E[e^X] = {E_eX:.4f}")

# Visualización de la transformación
x_vals = np.linspace(0, 1, 100)
plt.figure(figsize=(10, 6))
plt.plot(x_vals, f_uniforme(x_vals), 'b-', label='f(x) = 1', linewidth=2)
plt.plot(x_vals, np.exp(x_vals), 'r-', label='g(x) = e^x', linewidth=2)
plt.fill_between(x_vals, 0, np.exp(x_vals), alpha=0.3, color='red')
plt.title('Esperanza de g(X) = e^X para X ~ Uniforme(0,1)')
plt.xlabel('x')
plt.ylabel('Valor')
plt.legend()
plt.grid(True, alpha=0.3)
plt.savefig("esperanza_funcion.png", dpi=90)

# Verificación por simulación (Monte Carlo): promedio de g(X_i)
rng = np.random.default_rng(0)
print("Monte Carlo E[e^X] ≈", np.exp(rng.random(200_000)).mean(), " exacto:", np.e - 1)
```

Como $f = 1$ en $[0, 1],$ el área sombreada bajo $g(x)f(x) = e^x$ es justamente $E[e^X].$ La última línea muestra la idea del método de **Monte Carlo**: por la ley de los grandes números, el promedio de $g(X_1), \dots, g(X_n)$ para una muestra de $X$ aproxima $E[g(X)].$ Así se calculan integrales difíciles: se escriben como esperanzas y se simulan.

### 8. Ejercicios propuestos

1. Sea $X$ con distribución $P(X=1) = 0.1,$ $P(X=2) = 0.3,$ $P(X=3) = 0.4,$ $P(X=4) = 0.2.$ Calcule:
   - $E[X]$
   - $E[X^2]$
   - $E[2^X]$
   - $E[\sqrt{X}]$

2. Para $X \sim \text{Exponencial}(\lambda)$ con $f(x) = \lambda e^{-\lambda x}$ para $x \geq 0:$
   - Encuentre $E[X^n]$ para $n \in \mathbb{N}$
   - Calcule $E[e^{tX}]$ (función generadora de momentos)
   - Determine $E[\ln(X)]$

3. Demuestre que si $g(X) \geq 0,$ entonces $E[g(X)] \geq 0.$

4. Sea $X \sim N(0, 1).$ Calcule $E[|X|]$ usando el hecho de que:

   $$E[|X|] = \frac{1}{\sqrt{2\pi}} \int_{-\infty}^{\infty} |x| e^{-x^2/2} dx$$

5. Para una variable aleatoria $X$ con media $\mu$ y varianza $\sigma^2,$ encuentre:
   - $E[(X - a)^2]$ como función de $a$
   - El valor de $a$ que minimiza esta expresión

### Soluciones

**Ejercicio 1.**

- $E[X] = 0.1 + 0.6 + 1.2 + 0.8 = 2.7$
- $E[X^2] = 0.1 + 1.2 + 3.6 + 3.2 = 8.1$
- $E[2^X] = 2(0.1) + 4(0.3) + 8(0.4) + 16(0.2) = 0.2 + 1.2 + 3.2 + 3.2 = 7.8,$ mayor que $2^{2.7} \approx 6.50$
- $E[\sqrt{X}] = 0.1 + 0.3\sqrt{2} + 0.4\sqrt{3} + 0.2 \cdot 2 \approx 1.617,$ menor que $\sqrt{2.7} \approx 1.643,$ porque $\sqrt{x}$ es cóncava

**Ejercicio 2.**

- $E[X^n] = \int_0^\infty x^n\lambda e^{-\lambda x}\,dx = \frac{n!}{\lambda^n},$ con el cambio $u = \lambda x$ y $\Gamma(n + 1) = n!.$
- $E[e^{tX}] = \int_0^\infty \lambda e^{-(\lambda - t)x}\,dx = \frac{\lambda}{\lambda - t}$ para $t < \lambda;$ para $t \geq \lambda$ la integral diverge.
- $E[\ln X] = \int_0^\infty \ln x\,\lambda e^{-\lambda x}\,dx = -\gamma - \ln\lambda,$ donde $\gamma \approx 0.5772$ es la constante de Euler-Mascheroni; con $\lambda = 1$ es $-\gamma = \Gamma'(1).$

**Ejercicio 3.** Si $g(x) \geq 0,$ cada término de la suma, o el integrando, es no negativo, porque $p(x) \geq 0$ y $f(x) \geq 0;$ entonces la suma o la integral también lo es.

**Ejercicio 4.** Por simetría, $E[|X|] = \frac{2}{\sqrt{2\pi}}\int_0^\infty x e^{-x^2/2}\,dx = \frac{2}{\sqrt{2\pi}}\left[-e^{-x^2/2}\right]_0^\infty = \sqrt{\frac{2}{\pi}} \approx 0.798.$ Es la distancia media de una normal estándar a su centro, algo menor que la desviación estándar 1, como exige Jensen: $E[|X|] \leq \sqrt{E[X^2]}.$

**Ejercicio 5.** $E[(X - a)^2] = \sigma^2 + (\mu - a)^2,$ una parábola en $a$ que se minimiza en $a = \mu$ con valor mínimo $\sigma^2$ (tema 3.1).
