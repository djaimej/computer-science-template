# Probabilidad I - Espacio de Probabilidad

## 1.8 Simulación de ejemplos elementales para ilustrar la interpretación

---

### 1. Introducción

La **probabilidad** puede interpretarse de varias formas (clásica, frecuentista, subjetiva) y se formaliza con los axiomas de Kolmogórov. La **interpretación frecuentista** se entiende mejor mediante **simulación computacional**: al repetir muchas veces un experimento aleatorio en la computadora, las frecuencias relativas se aproximan a las probabilidades teóricas.

La simulación sirve para dos cosas: **ilustrar** resultados que ya se calcularon, y **estimar** probabilidades que son difíciles de calcular. Este tema se concentra en cómo simular experimentos elementales correctamente; el tema 1.9 estudia con más detalle qué tan rápido convergen las frecuencias y cuánto error tiene una estimación.

### 2. Definiciones clave

- **Probabilidad clásica (Laplace):**

$$ P(A) = \frac{\text{Casos favorables}}{\text{Casos posibles}}, \quad \text{si todos son equiprobables.} $$

- **Frecuencia relativa:** si repetimos un experimento $n$ veces, la frecuencia relativa de un evento $A$ es

$$ f_n(A) = \frac{N_n(A)}{n} $$

donde $N_n(A)$ es el número de veces que ocurre $A.$ La interpretación frecuentista identifica a $P(A)$ con el valor al que se acerca $f_n(A)$ cuando $n$ crece.

### 3. Cómo simula la computadora

Las computadoras son deterministas; los números "aleatorios" que producen son **pseudoaleatorios**: una sucesión calculada con una fórmula a partir de un valor inicial, la **semilla**, que pasa las pruebas estadísticas de aleatoriedad. Python usa el algoritmo Mersenne Twister. Con la misma semilla se obtiene siempre la misma sucesión, lo que hace **reproducibles** los experimentos.

La pieza básica es un número uniforme $U$ en $[0, 1),$ `random.random()`. A partir de él se simula cualquier experimento discreto:

- Un evento de probabilidad $p:$ ocurre si $U < p,$ porque $P(U < p) = p.$
- Un dado justo: $\lfloor 6U \rfloor + 1,$ o directamente `random.randint(1, 6)`.
- Un resultado con probabilidades $p_1, \dots, p_k:$ se divide $[0, 1)$ en intervalos consecutivos de longitudes $p_1, \dots, p_k$ y se elige aquel donde cae $U.$ Es lo que hace `random.choices(valores, weights=...)`.
- Extracciones **sin reemplazo**: `random.sample(urna, k)` elige $k$ elementos distintos, todos los subconjuntos ordenados con la misma probabilidad.

### 4. Ejemplos clásicos

#### Ejemplo 1: Lanzamiento de una moneda justa

- **Espacio muestral:** $\Omega = \{\text{Cara}, \text{Cruz}\}.$
- **Probabilidad teórica:**

$$ P(\text{Cara}) = P(\text{Cruz}) = \tfrac{1}{2} $$

Al simular muchos lanzamientos, la frecuencia relativa de caras tenderá a $0.5.$

#### Ejemplo 2: Lanzamiento de un dado

- **Espacio muestral:** $\Omega = \{1,2,3,4,5,6\}$
- **Probabilidad de sacar par:**

$$ P(\text{par}) = \frac{3}{6} = 0.5 $$

#### Ejemplo 3: Extracción de bolas de una urna

Una urna contiene 3 bolas rojas y 2 negras. Se extrae una al azar. Si se numeran las bolas, $\Omega = \{R_1, R_2, R_3, N_1, N_2\}$ es equiprobable y

$$ P(\text{Roja}) = \tfrac{3}{5}, \quad P(\text{Negra}) = \tfrac{2}{5} $$

#### Ejemplo 4: El problema del cumpleaños

¿Cuál es la probabilidad de que en un grupo de $k$ personas al menos dos cumplan años el mismo día? Ignorando los años bisiestos y suponiendo los 365 días igualmente probables, la probabilidad de que **todos** los cumpleaños sean distintos es $\frac{365}{365} \cdot \frac{364}{365} \cdots \frac{365 - k + 1}{365},$ así que

$$ P(\text{coincidencia}) = 1 - \prod_{i=0}^{k-1} \frac{365 - i}{365} $$

Con $k = 23$ ya es mayor que $\frac{1}{2},$ aproximadamente $0.507,$ mucho menos de lo que la intuición sugiere. Es un buen caso para comparar la fórmula con la simulación.

### 5. Simulación computacional (Python)

```python
import random
from math import prod

random.seed(2024)          # semilla fija: los resultados son reproducibles

# Moneda: evento de probabilidad 1/2
def simular_moneda(n, p=0.5):
    return sum(random.random() < p for _ in range(n)) / n

# Dado: frecuencia de pares
def simular_dado(n):
    return sum(random.randint(1, 6) % 2 == 0 for _ in range(n)) / n

# Urna: 3 rojas y 2 negras, una extracción
def simular_urna(n):
    urna = ["R", "R", "R", "N", "N"]
    return sum(random.choice(urna) == "R" for _ in range(n)) / n

for n in [10, 100, 1000, 10000]:
    print(f"n = {n:>5}: moneda {simular_moneda(n):.3f}  dado par {simular_dado(n):.3f}  urna roja {simular_urna(n):.3f}")
print("Teóricos:   0.500 0.500 0.600")

# Problema del cumpleaños: fórmula contra simulación
def p_cumple_teorica(k):
    return 1 - prod((365 - i) / 365 for i in range(k))

def p_cumple_simulada(k, n=20000):
    return sum(len(set(random.randrange(365) for _ in range(k))) < k for _ in range(n)) / n

for k in [10, 23, 40]:
    print(f"k = {k}: teórica {p_cumple_teorica(k):.3f}  simulada {p_cumple_simulada(k):.3f}")
```

Al aumentar $n,$ los valores simulados se acercan a los teóricos, pero **no de manera monótona**: con $n = 100$ es normal obtener 0.45 o 0.56. Lo que disminuye es el tamaño típico del error, que es del orden de $\frac{1}{\sqrt{n}}$ (tema 1.9).

### 6. Errores comunes al simular

- **Simular algo distinto de lo que se pregunta.** "Extraer dos bolas" sin reemplazo no es lo mismo que dos llamadas a `random.choice`, que extraen **con** reemplazo; se usa `random.sample`.
- **Usar `random.randint(0, 6)` para un dado.** En Python `randint` incluye ambos extremos y daría 7 valores; en cambio `random.randrange(6)` da $0, \dots, 5.$
- **Concluir con pocas repeticiones.** Una diferencia de 0.03 entre la frecuencia y el valor teórico no significa nada con $n = 100,$ pero sí con $n = 10^6.$
- **Fijar la semilla dentro del ciclo.** Repetiría el mismo "azar" en cada iteración.

### 7. Ejercicios propuestos

1. Simula 1,000 lanzamientos de una moneda y grafica la frecuencia relativa acumulada de **caras** en función de $n.$ ¿Tiende a $0.5?$

2. Simula 10,000 lanzamientos de un dado y estima $P(\text{número} \le 3),$ $P(\text{número} > 4)$ y $P(\text{número par}).$ Compáralos con los valores teóricos.

3. En una urna con 4 bolas rojas y 6 negras, simula 5,000 extracciones **con reemplazo** y estima $P(\text{Roja}).$

4. Modifica el código para simular un dado **no justo**, donde la probabilidad de cada cara es proporcional a su número: $P(\{i\}) = i/21.$

5. De la urna del ejercicio 3 se extraen dos bolas **sin reemplazo**. Estima por simulación la probabilidad de que ambas sean rojas y compárala con el valor exacto.

### 8. Soluciones

```python
import random
from fractions import Fraction

random.seed(7)
n = 10_000

# Ejercicio 2
tiradas = [random.randint(1, 6) for _ in range(n)]
print("P(≤3) ≈", sum(t <= 3 for t in tiradas) / n, "teórico 0.5")
print("P(>4) ≈", sum(t > 4 for t in tiradas) / n, "teórico", round(2 / 6, 4))
print("P(par) ≈", sum(t % 2 == 0 for t in tiradas) / n, "teórico 0.5")

# Ejercicio 3: con reemplazo
urna = ["R"] * 4 + ["N"] * 6
print("P(Roja) ≈", sum(random.choice(urna) == "R" for _ in range(5000)) / 5000, "teórico 0.4")

# Ejercicio 4: dado cargado con random.choices
cargado = random.choices(range(1, 7), weights=range(1, 7), k=n)
for cara in range(1, 7):
    print(cara, round(cargado.count(cara) / n, 3), "teórico", round(cara / 21, 3))

# Ejercicio 5: sin reemplazo
ambas = sum(random.sample(urna, 2) == ["R", "R"] for _ in range(n)) / n
print("P(ambas rojas) ≈", ambas, " exacto:", Fraction(4, 10) * Fraction(3, 9), "≈", round(4 / 10 * 3 / 9, 4))
```

En el ejercicio 4, `random.choices` con pesos $1, 2, \dots, 6$ elige cada cara con probabilidad proporcional a su peso, es decir $\frac{i}{21}.$ En el ejercicio 5, la probabilidad exacta es $\frac{4}{10} \cdot \frac{3}{9} = \frac{2}{15} \approx 0.133$ por la regla del producto (tema 1.5); si se extrajera con reemplazo sería $0.4^2 = 0.16.$ La solución del ejercicio 1 es la gráfica del tema 1.9.
