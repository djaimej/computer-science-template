# Estructuras Discretas - Inducción y recursión

## 3.2 Definiciones recursivas: definición de conjuntos y funciones mediante uso de patrones, ejemplos con estructuras de datos no numéricas (listas, árboles, expresiones lógicas, etc.).

---

### 1. Conceptos Fundamentales

#### Definición Recursiva

Una **definición recursiva** consta de:

1. **Caso(s) base**: Instancias mínimas no recursivas
2. **Paso recursivo**: Reglas para construir elementos nuevos a partir de existentes

**Estructura general**:

$$ \mathcal{D}(x) = \begin{cases} \text{Caso base} & \text{si } x \text{ es mínimo} \\\ \mathcal{F}(\mathcal{D}(y_1), \ldots, \mathcal{D}(y_k)) & \text{para } y_i \text{ componentes de } x \end{cases} $$

### 2. Ejemplos con Estructuras de Datos

#### Listas Enlazadas

**Definición recursiva**:

1. **Caso base**: Lista vacía $[]$
2. **Paso recursivo**: $[a] + \text{lista}$ (concatenación)

```python
def longitud(lista):
    if lista == []:  # Caso base
        return 0
    else:            # Paso recursivo
        return 1 + longitud(lista[1:])
```

#### Árboles Binarios

**Definición**:

1. **Caso base**: Árbol vacío $\emptyset$
2. **Paso recursivo**: Nodo con subárboles izquierdo/derecho

$$ \text{Árbol } T = \begin{cases} \emptyset & \\\ (n, T_{izq}, T_{der}) & \text{donde } T_{izq}, T_{der} \text{ son árboles} \end{cases} $$

```python
class Nodo:
    def __init__(self, val, izq=None, der=None):
        self.valor = val
        self.izquierdo = izq
        self.derecho = der
```

### 3. Expresiones Lógicas

**Definición recursiva**:

1. **Caso base**:
   - Variables proposicionales $(p, q, \ldots)$
   - Constantes ( $\top$, $\bot$ )

2. **Paso recursivo**:
   - $\neg \varphi$
   - $\varphi \land \psi$
   - $\varphi \lor \psi$

**Ejemplo**: $(\neg p \lor q) \land r$ se construye como:

1. $\neg p$ ( de $\neg$ aplicado a $p$ )
2. $(\neg p \lor q)$
3. Paso final con $\land r$

### 4. Conjuntos Recursivos

#### Ejemplo: Palíndromos

**Definición**:

1. **Casos base**:
   - $\varepsilon$ (cadena vacía)
   - $a$ para todo $a \in \Sigma$ (alfabeto)
2. **Regla recursiva**:
   - Si $w$ es palíndromo, entonces $awa$ también lo es

$$ \mathcal{P} = \{\varepsilon\} \cup \{a \mid a \in \Sigma\} \cup \{awa \mid w \in \mathcal{P}, a \in \Sigma\} $$

### 5. Funciones Recursivas No Numéricas

#### Conteo de Nodos en Árbol

$$ \text{contar}(T) = \begin{cases} 0 & \text{si } T = \emptyset \\\ 1 + \text{contar}(T_{izq}) + \text{contar}(T_{der}) & \text{si no} \end{cases} $$

```python
def contar_nodos(arbol):
    if arbol is None:
        return 0
    return 1 + contar_nodos(arbol.izquierdo) + contar_nodos(arbol.derecho)
```

### 6. Recursión Mutua

**Ejemplo**: Paridad de longitud en listas

- Función `es_par` llama a `es_impar` y viceversa

```python
def es_par(lista):
    if lista == []:
        return True
    return es_impar(lista[1:])

def es_impar(lista):
    if lista == []:
        return False
    return es_par(lista[1:])
```
