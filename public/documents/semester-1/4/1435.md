## 3.5 Propiedades de la integral

---

### 1. Propiedades Algebraicas de la Integral

#### 1.1 Linealidad de la Integral

La integral es un operador lineal. Para constantes $\alpha, \beta \in \mathbb{R}$ y funciones integrables $f$ y $g$:

$$ \int [\alpha f(x) + \beta g(x)]  dx = \alpha \int f(x)  dx + \beta \int g(x)  dx $$

**Ejemplo:**

$$ \int (3x^2 + 4\cos x)  dx = 3\int x^2  dx + 4\int \cos x  dx = x^3 + 4\sin x + C $$

#### 1.2 Aditividad del Intervalo

Para $a < b < c$:

$$ \int_a^c f(x)  dx = \int_a^b f(x)  dx + \int_b^c f(x)  dx $$

#### 1.3 Inversión de Límites

$$ \int_a^b f(x)  dx = -\int_b^a f(x)  dx $$

#### 1.4 Integral en un Punto

$$ \int_a^a f(x)  dx = 0 $$

### 2. Propiedades de Comparación

#### 2.1 Monotonía

Si $f(x) \leq g(x)$ para todo $x \in [a, b]$, entonces:

$$ \int_a^b f(x)  dx \leq \int_a^b g(x)  dx $$

#### 2.2 Acotación

Si $m \leq f(x) \leq M$ para todo $x \in [a, b]$, entonces:

$$ m(b - a) \leq \int_a^b f(x)  dx \leq M(b - a) $$

#### 2.3 Desigualdad Triangular

$$ \left| \int_a^b f(x)  dx \right| \leq \int_a^b |f(x)|  dx $$

### 3. Propiedades de Simetría

#### 3.1 Funciones Pares

Si $f$ es par ( $f(-x) = f(x)$ ):

$$ \int_{-a}^a f(x)  dx = 2\int_0^a f(x)  dx $$

#### 3.2 Funciones Impares

Si $f$ es impar ( $f(-x) = -f(x)$ ):

$$ \int_{-a}^a f(x)  dx = 0 $$

#### 3.3 Ejemplo de Simetría

```python
import numpy as np
import matplotlib.pyplot as plt

# Función par: f(x) = x²
x = np.linspace(-2, 2, 100)
y_par = x**2

# Función impar: f(x) = x³
y_impar = x**3

plt.figure(figsize=(12, 5))

plt.subplot(1, 2, 1)
plt.plot(x, y_par, 'b-', label='f(x) = x² (par)')
plt.fill_between(x, 0, y_par, alpha=0.3)
plt.title('Función Par: Área simétrica')
plt.legend()

plt.subplot(1, 2, 2)
plt.plot(x, y_impar, 'r-', label='f(x) = x³ (impar)')
plt.fill_between(x, 0, y_impar, where=y_impar>=0, alpha=0.3, color='red')
plt.fill_between(x, 0, y_impar, where=y_impar<=0, alpha=0.3, color='blue')
plt.title('Función Impar: Áreas canceladas')
plt.legend()

plt.tight_layout()
plt.show()
```

### 4. Teoremas Fundamentales

#### 4.1 Teorema del Valor Medio para Integrales

Si $f$ es continua en $[a, b]$, existe $c \in (a, b)$ tal que:

$$ \int_a^b f(x)  dx = f(c)(b - a) $$

#### 4.2 Teorema Fundamental del Cálculo

Si $f$ es continua en $[a, b]$ y $F$ es una primitiva de $f$:

$$ \int_a^b f(x)  dx = F(b) - F(a) $$

### 5. Implementación Computacional

#### 5.1 Verificación de Propiedades con Python

```python
import sympy as sp
import numpy as np

x = sp.symbols('x')
f = x**2
g = sp.sin(x)

# Propiedad de linealidad
alpha, beta = 2, 3
lhs = sp.integrate(alpha*f + beta*g, x)
rhs = alpha*sp.integrate(f, x) + beta*sp.integrate(g, x)
print(f"Linealidad: {sp.simplify(lhs) == sp.simplify(rhs)}")

# Propiedad de aditividad
a, b, c = 0, 1, 2
lhs = sp.integrate(f, (x, a, c))
rhs = sp.integrate(f, (x, a, b)) + sp.integrate(f, (x, b, c))
print(f"Aditividad: {sp.simplify(lhs) == sp.simplify(rhs)}")

# Propiedad de simetría (función impar)
f_impar = x**3
integral_simetrica = sp.integrate(f_impar, (x, -a, a))
print(f"Simetría impar: {sp.simplify(integral_simetrica) == 0}")
```

#### 5.2 Visualización del Teorema del Valor Medio

```python
# Teorema del valor medio
def f(x):
    return x**2

a, b = 0, 2
x_vals = np.linspace(a, b, 100)
y_vals = f(x_vals)

# Valor medio
integral_val = sp.integrate(x**2, (x, a, b)).evalf()
valor_medio = integral_val / (b - a)

# Punto c donde f(c) = valor medio
c = np.sqrt(valor_medio)

plt.figure(figsize=(10, 6))
plt.plot(x_vals, y_vals, 'b-', label='f(x) = x²')
plt.axhline(valor_medio, color='r', linestyle='--', label=f'Valor medio: {valor_medio:.2f}')
plt.axvline(c, color='g', linestyle='--', label=f'c = {c:.2f}')
plt.fill_between(x_vals, 0, y_vals, alpha=0.3)
plt.xlabel('x')
plt.ylabel('f(x)')
plt.title('Teorema del Valor Medio para Integrales')
plt.legend()
plt.grid(True)
plt.show()
```

### 6. Aplicaciones de las Propiedades

#### 6.1 Cálculo de Áreas

Las propiedades de simetría simplifican el cálculo de áreas en funciones pares e impares.

#### 6.2 Estimación de Integrales

Las propiedades de acotación permiten estimar integrales sin calcularlas exactamente.

#### 6.3 Simplificación de Cálculos

La linealidad permite descomponer integrales complejas en integrales más simples.
