# Estructuras de Datos - Árboles binarios de búsqueda

## 11.1 Definición, propiedades y TDA.

---

### 1. Definición

Un **Árbol Binario de Búsqueda (BST, Binary Search Tree)** es un árbol binario con la propiedad de que:

- Para cada nodo $n$, **todos los valores del subárbol izquierdo** son menores que $n.valor$.
- Para cada nodo $n$, **todos los valores del subárbol derecho** son mayores que $n.valor$.

Esto permite **búsquedas, inserciones y eliminaciones eficientes**.

### 2. Propiedades de los BST

1. **Altura:** $h$ depende de la estructura. Árbol balanceado: $h = O(\log n)$, desbalanceado: $h = O(n)$.
2. **Recorridos:** Preorden, Inorden, Postorden, BFS.
3. **Subárboles:** Cada nodo raíz de un subárbol es también un BST.
4. **Valores únicos:** Normalmente los BST contienen valores únicos, aunque pueden adaptarse a duplicados.
5. **Cotas de nodos:**
   - Número máximo de nodos en altura $h$: $$ n_{max} = 2^{h+1} - 1 $$
   - Altura mínima con $n$ nodos: $$ h_{min} = \lfloor \log_2 n \rfloor $$

### 3. TDA Árbol Binario de Búsqueda

| Operación             | Descripción                                                |
| --------------------- | ---------------------------------------------------------- |
| insertar(valor)       | Inserta un valor manteniendo la propiedad BST.             |
| eliminar(valor)       | Elimina un nodo y reorganiza subárboles para mantener BST. |
| buscar(valor)         | Retorna el nodo con el valor buscado o None si no existe.  |
| recorrido_inorden()   | Retorna elementos en orden ascendente.                     |
| recorrido_preorden()  | Visita raíz primero.                                       |
| recorrido_postorden() | Visita raíz al final.                                      |
| minimo()              | Retorna el valor mínimo.                                   |
| maximo()              | Retorna el valor máximo.                                   |

### 4. Implementación básica en Python

```python
class NodoBST:
    def __init__(self, valor):
        self.valor = valor
        self.izquierdo = None
        self.derecho = None

class BST:
    def __init__(self):
        self.raiz = None

    def insertar(self, valor):
        if not self.raiz:
            self.raiz = NodoBST(valor)
        else:
            self._insertar(self.raiz, valor)

    def _insertar(self, nodo, valor):
        if valor < nodo.valor:
            if nodo.izquierdo:
                self._insertar(nodo.izquierdo, valor)
            else:
                nodo.izquierdo = NodoBST(valor)
        else:  # los valores iguales van a la derecha: así se admiten duplicados
            if nodo.derecho:
                self._insertar(nodo.derecho, valor)
            else:
                nodo.derecho = NodoBST(valor)

    def inorden(self, nodo):
        if nodo:
            self.inorden(nodo.izquierdo)
            print(nodo.valor, end=' ')
            self.inorden(nodo.derecho)

# Ejemplo de uso
arbol = BST()
arbol.insertar(10)
arbol.insertar(5)
arbol.insertar(15)
arbol.insertar(2)
arbol.insertar(7)
arbol.inorden(arbol.raiz)  # Salida: 2 5 7 10 15
```

### 5. Ventajas de los BST

- **Búsqueda eficiente:** Promedio $O(\log n)$.
- **Inserción y eliminación rápidas:** Promedio $O(\log n)$.
- **Recorridos ordenados:** Inorden devuelve los elementos en orden ascendente.
- **Base para estructuras avanzadas:** árboles AVL y rojinegros, que son ABB balanceados, y árboles B, que generalizan la idea a nodos con muchas claves. Los heaps, en cambio, no son árboles de búsqueda: solo ordenan cada nodo respecto a sus hijos.
