## 3.2 Expresiones y cadenas.

---

### 1. Definiciones Clave

#### 1.1 Expresiones

Combinación de operandos y operadores que producen un valor:

$$ \text{Expresión} = \text{Operando}_1 \circ \text{Operador} \circ \text{Operando}_2 $$

**Ejemplo:**

```java
int resultado = (5 + 3) * 2;  // Expresión aritmética
boolean esValido = edad >= 18; // Expresión booleana
```

#### 1.2 Cadenas (Strings)

Secuencia de caracteres representando texto:  
$$ \text{Cadena} = \{c_1, c_2, ..., c_n\} \quad \text{donde} \quad c_i \in \text{Unicode} $$

### 2. Operaciones con Cadenas

#### 2.1 Concatenación

Unión de cadenas usando `+`:

```python
nombre = "Juan"
saludo = "Hola " + nombre  # Resultado: "Hola Juan"
```

#### 2.2 Interpolación

Inserción de valores en cadenas (Python/JavaScript):

```javascript
const edad = 25;
const mensaje = `Tengo ${edad} años`;
```

#### 2.3 Métodos Comunes

| Método          | Descripción                | Ejemplo                         |
| --------------- | -------------------------- | ------------------------------- |
| `length()`      | Longitud de la cadena      | `"abc".length()` → 3            |
| `substring()`   | Extraer parte de la cadena | `"hello".substring(1,3)` → "el" |
| `toLowerCase()` | Convertir a minúsculas     | `"ABC".toLowerCase()` → "abc"   |

### 4. Expresiones Regulares (Regex)

Patrones para búsqueda/validación de textos:

#### 4.1 Sintaxis Básica

- `\d`: Dígito (equivalente a `[0-9]`)
- `\w`: Carácter alfanumérico
- `^`: Inicio de cadena

**Ejemplo (Java):**

```java
boolean valido = "A123".matches("^[A-Z]\\d{3}$");  // true
```

#### 4.2 Ecuación de Coincidencia

$$ \text{Coincidencia} = \begin{cases} 1 & \text{si } \text{cadena} \in \mathcal{L}(\text{patrón}) \\\ 0 & \text{en otro caso} \end{cases} $$
