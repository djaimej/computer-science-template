# Estructuras Discretas - Introducción

## 1.1 ¿Qué son las estructuras discretas?

---

Las **estructuras discretas** son objetos matemáticos que estudian conjuntos cuyos elementos son distintos y separados (no continuos). Son fundamentales en ciencias de la computación, matemáticas y lógica para modelar relaciones discretas, estructuras de datos y problemas algorítmicos.

**Fórmula de cardinalidad discreta**:

Para un conjunto finito $A$ con $n$ elementos:  

$$ |A| = n \quad \text{y} \quad \mathcal{P}(A) = 2^n $$

donde $\mathcal{P}(A)$ es el conjunto potencia.

### Características Clave

| **Propiedad**     | **Descripción**                           | **Ejemplo**                        |
| ----------------- | ----------------------------------------- | ---------------------------------- |
| **Discreción**    | Elementos separados y distinguibles       | $\mathbb{Z}$, vértices en un grafo |
| **Numerabilidad** | Pueden ser finitos o infinitos numerables | $\mathbb{N}$, lenguajes formales   |
| **Aplicabilidad** | Base teórica para CS                      | Algoritmos, criptografía           |

### Ejemplos Básicos

1. **Conjuntos**: Colección de elementos únicos.

```python
  A = {1, 2, 3, 4}  # Conjunto en Python
  B = {3, 4, 5, 6}
  print(A.union(B))  # Unión: {1, 2, 3, 4, 5, 6}
```

2. **Grafos**: Pares ordenados $G = (V, E)$, donde $V$ son vértices y $E$ aristas.

```python
  grafo = {
      'A': ['B', 'C'],
      'B': ['A', 'D'],
      'C': ['A'],
      'D': ['B']
  }
```

##### **3.1. Conjuntos y Relaciones**

```typescript
// Operaciones básicas de conjuntos
const A = new Set([1, 2, 3]);
const B = new Set([3, 4, 5]);

// Unión: A ∪ B
const union = new Set([...A, ...B]); // {1, 2, 3, 4, 5}

// Intersección: A ∩ B
const intersection = new Set([...A].filter((x) => B.has(x))); // {3}
```

### Fórmulas Importantes

- **Principio de Adición** (para conjuntos disjuntos):

$$ |A \cup B| = |A| + |B| \quad \text{si } A \cap B = \emptyset  $$

- **Principio de Multiplicación** (eventos independientes):  
  Si hay $m$ formas de hacer $X$ y $n$ formas de hacer $Y$, hay $m \times n$ formas de hacer ambas.

- **Permutaciones** (ordenaciones de $n$ elementos):

$$ P(n) = n! $$

### Conceptos Relacionados

- **Funciones Booleanas**:

$ f(x, y) = x \land y $ (AND lógico).

- **Relaciones**:  
  Una relación $R$ en un conjunto $A$ es un subconjunto de $A \times A$.
