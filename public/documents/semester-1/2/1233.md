# Estructuras Discretas - Inducción y recursión

## 3.3 Inducción estructural: principios de inducción estructural, dualidad entre inducción y recursión, ejemplos de demostración en diversas estructuras.

---

### 1. Principio de Inducción Estructural

#### Definición Formal

Dado un conjunto $A$ definido recursivamente:

1. **Base**: Probar $P(x)$ para todos los casos base de $A$
2. **Paso Inductivo**: Para cada regla constructora $x = f(y_1,...,y_k)$, asumir $P(y_i)$ y demostrar $P(x)$

$$ \frac{\forall \text{ casos base } b \in A. P(b) \quad \forall \text{ reglas } f. (\forall i. P(y_i)) \Rightarrow P(f(y_1,...,y_k))}{\forall x \in A. P(x)} $$

### 2. Dualidad Inducción-Recursión

| Concepto       | Inducción                            | Recursión                               |
| -------------- | ------------------------------------ | --------------------------------------- |
| **Dirección**  | De lo simple a lo complejo (pruebas) | De lo complejo a lo simple (cómputo)    |
| **Estructura** | Usa casos base y constructores       | Define casos base y llamadas recursivas |

**Ejemplo para listas**:

```haskell
-- haskell
-- Recursión (cómputo)
longitud [] = 0
longitud (x:xs) = 1 + longitud xs

-- Inducción (pruebo)
-- Base: longitud [] = 0 ✓
-- Paso: Asumo longitud xs = n, pruebo longitud (x:xs) = n+1 ✓
```

### 3. Demostraciones por Inducción Estructural

#### Árboles Binarios

**Propiedad**: Número de hojas = Número de nodos internos + 1

**Demostración**:

1. **Base**: Árbol vacío (0=0+1? No, caso especial) Hoja única: 1=0+1 ✓

2. **Paso**: Para $T = (v, T_{izq}, T_{der})$, asumimos:

$$ hojas(T_{izq}) = nodos(T_{izq}) + 1 \quad \text{y} \quad hojas(T_{der}) = nodos(T_{der}) + 1  $$

Entonces:

$ hojas(T) = hojas(T_{izq}) + hojas(T_{der}) = (nodos(T_{izq}) + 1) + (nodos(T_{der}) + 1) $

Pero:

$ nodos(T) = 1 + nodos(T_{izq}) + nodos(T_{der}) $,

luego:

$ hojas(T) = (nodos(T) - 1) + 2 = nodos(T) + 1 \quad $ ✗

**Corrección**: Solo vale si ambos sub-árboles no son vacíos.

#### Expresiones Lógicas

**Propiedad**: Toda fórmula tiene igual número de paréntesis abiertos y cerrados

**Demostración**:

1. **Base**:
   - Variable $p$: 0=0 ✓
2. **Paso**:
   - $\neg \varphi$: Igual que $\varphi$ ✓
   - $\varphi \land \psi$: $par(\varphi) + par(\psi) = par(\varphi) + par(\psi)$ ✓

### 4. Esquema General para Estructuras

1. **Identificar constructores**:
   - Listas: [] y (:)
   - Árboles: Hoja y Nodo
2. **Definir medida**:
   - Altura, tamaño, profundidad
3. **Aplicar inducción**:
   - Casos base directos
   - Pasos por cada constructor

### 5. Ejemplo Avanzado: Grafos

**Propiedad**: Todo árbol con $n$ vértices tiene $n-1$ aristas

**Demostración inductiva**:

1. **Base**: $n=1$ (0 aristas) ✓
2. **Paso**:
   - Quitar una hoja, queda $n-1$ vértices
   - Por HI: tiene $(n-1)-1 = n-2$ aristas
   - Al añadir la hoja: +1 arista → $n-1$ total ✓

### 6. Errores Comunes

1. **Olvidar casos base no estándar**:
   - Árboles vacíos vs. hojas
2. **Suponer que todos los constructores preservan la propiedad**:
   - Ejemplo: no toda operación en listas mantiene el orden
