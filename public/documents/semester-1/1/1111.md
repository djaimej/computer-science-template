# Álgebra Superior I - Conjuntos
## 1.1 Noción intuitiva e igualdad de conjuntos. Subconjuntos. Conjunto vacío. Conjunto universal.

---

La teoría de conjuntos es el lenguaje común de toda la matemática moderna. Georg Cantor la desarrolló sistemáticamente a finales del siglo XIX y desde entonces sirve de fundamento para la lógica, el álgebra, el análisis y, por supuesto, las ciencias de la computación. En este subtema se establecen los conceptos primitivos y la notación estándar que se usarán a lo largo de todo el curso.

### 1. Noción intuitiva de conjunto

Partimos de una perspectiva intuitiva pero rigurosa: un **conjunto** es una colección bien definida de objetos distintos, llamados **elementos** o **miembros**. "Bien definida" significa que es posible determinar sin ambigüedad si un objeto dado pertenece o no a la colección.

Los conceptos primitivos (no definidos formalmente) de la teoría son:

- **Conjunto** ( $C$ )
- **Elemento** ( $e$ )
- **Relación de pertenencia** ( $\in$ )

> **Notación.** Si el objeto $e$ es elemento del conjunto $C$, escribimos $e \in C$ y leemos "e pertenece a C". Si no pertenece, escribimos $e \notin C$.

**Formas de definir un conjunto:**

1. **Por extensión** (listando sus elementos): $A = \{1, 2, 3, 4\}$
2. **Por comprensión** (mediante una propiedad): $B = \{x \in \mathbb{Z} \mid x > 0 \text{ y } x \leq 4\} = \{1,2,3,4\}$

**Ejemplos:**
- $\mathbb{N} = \{1, 2, 3, \ldots\}$ — números naturales.
- $V = \{a, e, i, o, u\}$ — vocales del español.
- $P = \{x \in \mathbb{Z} \mid x \text{ es primo}\} = \{2, 3, 5, 7, 11, \ldots\}$

### 2. Igualdad de conjuntos

Dos conjuntos $A$ y $B$ son **iguales** si y solo si contienen exactamente los mismos elementos. El orden de los elementos y su posible repetición en la descripción no afectan la igualdad.

**Definición formal:**
$$A = B \quad \Longleftrightarrow \quad \forall x,\; (x \in A \leftrightarrow x \in B)$$

**Ejemplos:**
- $\{1, 2, 3\} = \{3, 1, 2\} = \{1, 1, 2, 3\}$ (el orden y la repetición no importan).
- $\{x \in \mathbb{R} \mid x^2 = 1\} = \{-1, 1\}$.

**Estrategia para demostrar $A = B$:** se demuestra $A \subseteq B$ y $B \subseteq A$ simultáneamente (doble contención). Esta técnica aparecerá constantemente en el curso.

### 3. Subconjuntos

#### 3.1 Definición

Un conjunto $A$ es **subconjunto** de $B$, denotado $A \subseteq B$, si todo elemento de $A$ es también elemento de $B$.

$$A \subseteq B \quad \Longleftrightarrow \quad \forall x,\; (x \in A \rightarrow x \in B)$$

#### 3.2 Subconjunto propio

$A$ es **subconjunto propio** de $B$, denotado $A \subsetneq B$ (o $A \subset B$ según el autor), si $A \subseteq B$ pero $A \neq B$.

$$A \subsetneq B \quad \Longleftrightarrow \quad (A \subseteq B) \land (A \neq B)$$

#### 3.3 Propiedades de la inclusión

| Propiedad | Enunciado |
|---|---|
| **Reflexividad** | $A \subseteq A$ para todo $A$ |
| **Antisimetría** | Si $A \subseteq B$ y $B \subseteq A$, entonces $A = B$ |
| **Transitividad** | Si $A \subseteq B$ y $B \subseteq C$, entonces $A \subseteq C$ |

> **Nota.** Estas tres propiedades hacen de $\subseteq$ un **orden parcial** en cualquier colección de conjuntos. El concepto de orden parcial se estudia formalmente en Estructuras Discretas (subtema 4.1).

**Demostración de la transitividad:**

Sea $x \in A$. Como $A \subseteq B$, se tiene $x \in B$. Como $B \subseteq C$, se tiene $x \in C$. Por lo tanto $A \subseteq C$. $\square$

**Ejemplo:**
$$\{2, 4\} \subsetneq \{1, 2, 3, 4\} \subsetneq \mathbb{N} \subsetneq \mathbb{Z} \subsetneq \mathbb{Q} \subsetneq \mathbb{R}$$

### 4. Conjunto vacío

El **conjunto vacío** $\varnothing$ (también escrito $\{\}$) es el único conjunto que no contiene ningún elemento.

**Propiedad fundamental:** El conjunto vacío es subconjunto de todo conjunto.

$$\forall A,\; \varnothing \subseteq A$$

**Demostración:** Para probar $\varnothing \subseteq A$ hay que verificar:

$$" \text{todo elemento de } \varnothing \text{ pertenece a }A "$$ 

Como $\varnothing$ no tiene elementos, la condición se cumple vacuamente (no existe ningún $x$ que la viole). $\square$

**Observación importante:**
- $\varnothing \neq \{\varnothing\}$. El primero es el conjunto vacío; el segundo es un conjunto con un único elemento (que resulta ser el vacío).
- $|\varnothing| = 0$, mientras que $|\{\varnothing\}| = 1$.

### 5. Conjunto universal

En un contexto matemático dado, el **conjunto universal** $U$ es el conjunto que contiene todos los objetos bajo consideración en ese contexto. No es un concepto absoluto sino relativo al marco de trabajo.

**Propiedad:** Para cualquier conjunto $A$ definido dentro del universo $U$:
$$A \subseteq U$$

**Ejemplos según contexto:**
- Aritmética elemental: $U = \mathbb{N}$ o $U = \mathbb{Z}$.
- Análisis real: $U = \mathbb{R}$.
- Teoría de grafos: $U$ = el conjunto de vértices del grafo en cuestión.

> **Conexión con CC.** En bases de datos relacionales, el conjunto universal equivale al dominio de un atributo: el conjunto de todos los valores posibles que dicho atributo puede tomar. La definición precisa de dominio que estudiará en Estructuras de Datos (Semestre 2) descansa en esta noción.

### Ejercicios propuestos

1. **Igualdad.** Sean $P = \{2, 4, 6\}$ y $Q = \{4, 6, 2, 6\}$. Demuestra formalmente que $P = Q$ usando la definición.

2. **Subconjuntos.** Para $X = \{1, 2\}$, $Y = \{1, 2, 3\}$ y $Z = \{1\}$:
   - (a) ¿Es $X \subseteq Y$? ¿Es $X \subsetneq Y$?
   - (b) ¿Es $Z \subsetneq Y$? Justifica.
   - (c) ¿Es $Y \subseteq X$? ¿Por qué?

3. **Vacío y universal.** Determina verdadero o falso y justifica:
   - (a) $\varnothing \subseteq \{\varnothing\}$
   - (b) $\varnothing \in \{\varnothing\}$
   - (c) $\{\varnothing\} \subseteq \{\varnothing, \{1\}\}$
   - (d) $\{\varnothing\} \in \{\varnothing, \{1\}\}$

4. **Transitividad.** Si $A \subsetneq B$ y $B \subsetneq C$, ¿se puede concluir $A \subsetneq C$? Demuéstralo o da un contraejemplo.

5. **Antisimetría.** Usa la antisimetría de $\subseteq$ para demostrar que si $\{1, 2\} \subseteq \{x \in \mathbb{N} \mid x \leq 2\}$ y $\{x \in \mathbb{N} \mid x \leq 2\} \subseteq \{1, 2\}$, entonces los dos conjuntos son iguales.
