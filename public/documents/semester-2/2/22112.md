# Estructuras de Datos - Árboles binarios de búsqueda

## 11.2 Algoritmos de inserción, remoción y recuperación de elementos, complejidad.

---

### 1. Introducción

Un **Árbol Binario de Búsqueda (BST)** permite organizar datos de forma que la búsqueda, inserción y eliminación sean eficientes. Cada nodo cumple con la propiedad:

- Todos los valores del subárbol izquierdo < valor del nodo < todos los valores del subárbol derecho

Esta guía detalla los algoritmos fundamentales y su complejidad.

### 2. Inserción

#### 2.1 Algoritmo

1. Si el árbol está vacío, el nuevo nodo se convierte en la raíz.
2. Compara el valor a insertar con el nodo actual.
   - Si es menor, ir al subárbol izquierdo.
   - Si es mayor, ir al subárbol derecho.
3. Repetir recursivamente hasta encontrar posición vacía.

#### 2.2 Implementación en Python

```python
class NodoBST:
    def __init__(self, valor):
        self.valor = valor
        self.izquierdo = None
        self.derecho = None

def insertar(nodo, valor):
    if not nodo:
        return NodoBST(valor)
    if valor < nodo.valor:
        nodo.izquierdo = insertar(nodo.izquierdo, valor)
    else:
        nodo.derecho = insertar(nodo.derecho, valor)
    return nodo
```

#### 2.3 Complejidad

- Promedio: $O(\log n)$
- Peor caso (árbol degenerado): $O(n)$

### 3. Remoción

#### 3.1 Casos de eliminación

1. **Nodo hoja:** Eliminar directamente.
2. **Nodo con un hijo:** Reemplazar nodo por su hijo.
3. **Nodo con dos hijos:**
   - Encontrar sucesor inorden (mínimo del subárbol derecho).
   - Reemplazar valor del nodo por sucesor.
   - Eliminar sucesor.

#### 3.2 Implementación en Python

```python
def eliminar(nodo, valor):
    if not nodo:
        return None
    if valor < nodo.valor:
        nodo.izquierdo = eliminar(nodo.izquierdo, valor)
    elif valor > nodo.valor:
        nodo.derecho = eliminar(nodo.derecho, valor)
    else:
        if not nodo.izquierdo:
            return nodo.derecho
        if not nodo.derecho:
            return nodo.izquierdo
        temp = nodo.derecho
        while temp.izquierdo:
            temp = temp.izquierdo
        nodo.valor = temp.valor
        nodo.derecho = eliminar(nodo.derecho, temp.valor)
    return nodo
```

#### 3.3 Complejidad

- Promedio: $O(\log n)$
- Peor caso: $O(n)$

### 4. Recuperación / Búsqueda

#### 4.1 Algoritmo

1. Compara valor buscado con nodo actual.
2. Si coincide, retornar nodo.
3. Si es menor, buscar en subárbol izquierdo; si es mayor, en subárbol derecho.

#### 4.2 Implementación en Python

```python
def buscar(nodo, valor):
    if not nodo or nodo.valor == valor:
        return nodo
    if valor < nodo.valor:
        return buscar(nodo.izquierdo, valor)
    else:
        return buscar(nodo.derecho, valor)
```

#### 4.3 Complejidad

- Promedio: $O(\log n)$
- Peor caso: $O(n)$

### 5. Observaciones sobre complejidad

- La eficiencia depende del **balance del árbol**.
- Árboles desbalanceados pueden degradar rendimiento a $O(n)$.
- Árboles balanceados (AVL, Red-Black) garantizan $O(\log n)$ para todas las operaciones.
