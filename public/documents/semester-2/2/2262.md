# Estructuras de Datos - Listas

## 6.2 Inserción, remoción y recuperación de elementos en una Lista.

---

### 1. Definición de Lista

Una **lista** es una estructura de datos lineal y dinámica que permite almacenar una colección de elementos ordenados, donde cada elemento conoce a su sucesor (y en el caso de listas doblemente ligadas, también a su predecesor).

Existen varios tipos de listas:

- **Lista simplemente ligada**: cada nodo tiene un dato y un puntero al siguiente nodo.
- **Lista doblemente ligada**: cada nodo apunta tanto al anterior como al siguiente.
- **Lista circular**: el último nodo apunta nuevamente al primero.

### 2. Operaciones Fundamentales

#### 2.1 Inserción

Agregar un nuevo elemento en una posición determinada de la lista.

Casos comunes:

1. Inserción al inicio.
2. Inserción al final.
3. Inserción en una posición intermedia.

#### 2.2 Remoción

Eliminar un nodo de la lista.

Casos comunes:

1. Eliminación del primer nodo.
2. Eliminación del último nodo.
3. Eliminación en una posición intermedia.

#### 2.3 Recuperación (Búsqueda)

Acceder a un elemento en la lista dado su índice o valor.

### 4. Inserción en una Lista Simplemente Ligada

#### Algoritmo (caso general en pseudocódigo)

1. Crear un nuevo nodo.
2. Asignar el dato al nodo.
3. Ajustar los punteros:
   - $nuevo.siguiente \gets actual.siguiente$
   - $actual.siguiente \gets nuevo$

#### Ejemplo en C

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct Nodo {
    int dato;
    struct Nodo* siguiente;
} Nodo;

void insertarInicio(Nodo** cabeza, int valor) {
    Nodo* nuevo = (Nodo*)malloc(sizeof(Nodo));
    nuevo->dato = valor;
    nuevo->siguiente = *cabeza;
    *cabeza = nuevo;
}

void imprimir(Nodo* cabeza) {
    while (cabeza != NULL) {
        printf("%d -> ", cabeza->dato);
        cabeza = cabeza->siguiente;
    }
    printf("NULL\n");
}

int main() {
    Nodo* lista = NULL;
    insertarInicio(&lista, 10);
    insertarInicio(&lista, 20);
    insertarInicio(&lista, 30);
    imprimir(lista);
    return 0;
}
```

### 5. Remoción en una Lista

#### Algoritmo (eliminar un nodo por valor)

1. Buscar el nodo con el valor.
2. Guardar referencia al nodo anterior.
3. Ajustar punteros: $anterior.siguiente \gets actual.siguiente$
4. Liberar la memoria del nodo eliminado.

#### Ejemplo en C

```c
void eliminar(Nodo** cabeza, int valor) {
    Nodo* temp = *cabeza;
    Nodo* anterior = NULL;

    while (temp != NULL && temp->dato != valor) {
        anterior = temp;
        temp = temp->siguiente;
    }

    if (temp == NULL) return; // no encontrado

    if (anterior == NULL) {
        *cabeza = temp->siguiente; // eliminar cabeza
    } else {
        anterior->siguiente = temp->siguiente;
    }
    free(temp);
}
```

### 6. Recuperación de Elementos

#### Búsqueda por índice (0-based)

#### Ejemplo en Python

```python
class Nodo:
    def __init__(self, dato):
        self.dato = dato
        self.siguiente = None

class Lista:
    def __init__(self):
        self.cabeza = None

    def insertar(self, valor):
        nuevo = Nodo(valor)
        nuevo.siguiente = self.cabeza
        self.cabeza = nuevo

    def buscar_por_indice(self, indice):
        actual = self.cabeza
        i = 0
        while actual is not None:
            if i == indice:
                return actual.dato
            actual = actual.siguiente
            i += 1
        return None

lista = Lista()
lista.insertar(10)
lista.insertar(20)
lista.insertar(30)
print("Elemento en índice 1:", lista.buscar_por_indice(1))
```

### 7. Complejidad de las Operaciones

| Operación             | Lista simplemente ligada | Lista doblemente ligada                     |
| --------------------- | ------------------------ | ------------------------------------------- |
| Inserción al inicio   | $O(1)$                   | $O(1)$                                      |
| Inserción al final    | $O(n)$                   | $O(1)$ (si se mantiene referencia al final) |
| Eliminación al inicio | $O(1)$                   | $O(1)$                                      |
| Eliminación al final  | $O(n)$                   | $O(1)$                                      |
| Búsqueda por índice   | $O(n)$                   | $O(n)$                                      |

### 8. Conclusiones

- Las **listas** son estructuras dinámicas que permiten inserción y eliminación eficientes en posiciones conocidas.
- La **recuperación** de elementos por índice no es tan eficiente como en arreglos ( $O(n)$ vs $O(1)$ ).
- Las **listas doblemente ligadas** ofrecen mayor flexibilidad a cambio de más memoria (almacenan punteros extras).
