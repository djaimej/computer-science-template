### 2. Minimización de Funciones Booleanas

#### Métodos

- **Mapas de Karnaugh**: Visualización para simplificar funciones hasta 4 variables.
- **Algoritmo de Quine-McCluskey**: Para más de 4 variables.

**Ejemplo**: Minimizar $f(A,B,C) = \sum(0,2,4,6)$

Mapa de Karnaugh para $f$:

```
\  AB 00 01 11 10
C
0    1  0  0  1
1    1  0  0  1
```

**Resultado**: $f = \overline{C}$

### 3. Contadores

#### Contador Síncrono de 2 bits

Implementa secuencia 00 → 01 → 10 → 11 → 00...

**Ecuaciones de estado**:

- $D_0 = \overline{Q_0}$
- $D_1 = Q_0 \oplus Q_1$

**Implementación con flip-flops D**:

```python
# Simulación en Python
Q0, Q1 = 0, 0
for _ in range(4):
    D0 = not Q0
    D1 = Q0 ^ Q1
    Q0, Q1 = int(D0), int(D1)
    print(f"{Q1}{Q0}")
```

_Salida_: 01, 10, 11, 00

### 4. Multiplexores (MUX)

#### MUX 4:1

Selecciona 1 de 4 entradas usando 2 líneas de control $(S_0S_1)$.

**Ecuación lógica**:  

$$ f = \overline{S_0}\overline{S_1}D_0 + \overline{S_0}S_1D_1 + S_0\overline{S_1}D_2 + S_0S_1D_3 $$

**Implementación con compuertas**:

```
D0 --|
     AND---- OR
D1 --|      |
...       Salida
```

### 5. Circuitos Combinacionales vs. Secuenciales

| Característica | Combinacional          | Secuencial                |
| -------------- | ---------------------- | ------------------------- |
| **Salida**     | Solo entradas actuales | Entradas + estado interno |
| **Ejemplos**   | Multiplexores          | Contadores                |
| **Memoria**    | No                     | Sí (flip-flops)           |

### 6. Fórmulas Clave

- **Ley de DeMorgan para compuertas**:  
  $\overline{A \cdot B} = \overline{A} + \overline{B}$
- **Conversión binario a lógica**:  
  Para $n$ variables, hay $2^n$ combinaciones en tabla de verdad.
