## 3.2 Integral definida

---

### 1. Concepto de Integral Definida

#### 1.1 Definición Formal

La integral definida de una función $f(x)$ en el intervalo $[a, b]$ se define como el límite de las sumas de Riemann:

$$ \int_{a}^{b} f(x)  dx = \lim_{n \to \infty} \sum_{i=1}^{n} f(x_i^*) \Delta x $$

donde $\Delta x = \frac{b - a}{n}$ y $x_i^* \in [x_{i-1}, x_i]$.

#### 1.2 Interpretación Geométrica

Si $f(x) \geq 0$ en $[a, b]$, la integral definida representa el área bajo la curva $y = f(x)$ desde $x = a$ hasta $x = b$.

### 2. Propiedades de la Integral Definida

#### 2.1 Propiedades Fundamentales

1. **Linealidad**:

$$ \int_{a}^{b} [\alpha f(x) + \beta g(x)]  dx = \alpha \int_{a}^{b} f(x)  dx + \beta \int_{a}^{b} g(x)  dx $$

2. **Aditividad del intervalo**:

$$ \int_{a}^{b} f(x)  dx = \int_{a}^{c} f(x)  dx + \int_{c}^{b} f(x)  dx $$

3. **Inversión de límites**:

$$ \int_{a}^{b} f(x)  dx = -\int_{b}^{a} f(x)  dx $$

4. **Integral de una constante**:

$$ \int_{a}^{b} c  dx = c(b - a) $$

#### 2.2 Desigualdades

- Si $f(x) \leq g(x)$ en $[a, b]$, entonces:  
  $$ \int_{a}^{b} f(x)  dx \leq \int_{a}^{b} g(x)  dx $$

- **Desigualdad triangular**:

$$ \left| \int_{a}^{b} f(x)  dx \right| \leq \int_{a}^{b} |f(x)|  dx $$

### 3. Teorema Fundamental del Cálculo

#### 3.1 Primera Parte

Si $f$ es continua en $[a, b]$ y $F$ es una primitiva de $f$, entonces:  
$$ \int_{a}^{b} f(x)  dx = F(b) - F(a) $$

#### 3.2 Segunda Parte

Si $f$ es continua en $[a, b]$, entonces la función:  
$$ G(x) = \int_{a}^{x} f(t)  dt $$  
es derivable y $G'(x) = f(x)$.

#### 3.3 Notación

$$ \int_{a}^{b} f(x)  dx = F(x) \Big|_{a}^{b} = F(b) - F(a) $$

### 4. Implementación Computacional

#### 4.1 Cálculo Simbólico con Python

```python
import sympy as sp

# Cálculo simbólico de integral definida
x = sp.symbols('x')
f = x**2 + 3*x + 2

# Integral definida desde 0 hasta 2
integral_definida = sp.integrate(f, (x, 0, 2))
print(f"∫₀² (x² + 3x + 2) dx = {integral_definida}")

# Evaluación numérica
valor_numerico = integral_definida.evalf()
print(f"Valor numérico: {valor_numerico}")
```

#### 4.2 Integración Numérica

```python
import numpy as np
from scipy.integrate import quad

# Función a integrar
def f(x):
    return x**2 + 3*x + 2

# Integración numérica
resultado, error = quad(f, 0, 2)
print(f"∫₀² (x² + 3x + 2) dx ≈ {resultado:.6f}")
print(f"Error estimado: {error:.2e}")

# Visualización
x_vals = np.linspace(-1, 3, 400)
y_vals = f(x_vals)

import matplotlib.pyplot as plt
plt.figure(figsize=(10, 6))
plt.plot(x_vals, y_vals, 'b-', label='f(x) = x² + 3x + 2')
plt.fill_between(x_vals, 0, y_vals, where=(x_vals>=0)&(x_vals<=2),
                 alpha=0.3, color='green', label='Área bajo la curva')
plt.xlabel('x')
plt.ylabel('f(x)')
plt.title('Integral Definida: Área bajo la curva')
plt.legend()
plt.grid(True)
plt.show()
```

### 5. Aplicaciones de la Integral Definida

#### 5.1 Cálculo de Áreas

- Área bajo una curva: $\int_{a}^{b} f(x)  dx$
- Área entre curvas: $\int_{a}^{b} |f(x) - g(x)|  dx$

#### 5.2 Volúmenes de Sólidos de Revolución

- Método del disco: $\pi \int_{a}^{b} [f(x)]^2  dx$
- Método de la arandela: $\pi \int_{a}^{b} ([f(x)]^2 - [g(x)]^2)  dx$

#### 5.3 Longitud de Arco

$$ L = \int_{a}^{b} \sqrt{1 + [f'(x)]^2}  dx $$

#### 5.4 Trabajo en Física

$$ W = \int_{a}^{b} F(x)  dx $$
