# Introducción a las Ciencias de la Computación - Herencia

## 5.1 Extensión de clases

---

### 1. Concepto de Herencia y Extensión

#### 1.1 Definición

Mecanismo que permite crear nuevas clases a partir de clases existentes, heredando sus atributos y métodos:

$$ \text{Subclase} = \text{Superclase} + \text{Nuevos miembros} - \text{Miembros ocultados} $$

#### 1.2 Terminología

- **Superclase/Clase base**: Clase que se hereda
- **Subclase/Clase derivada**: Clase que hereda
- **Relación "es-un"**: Fundamenta la herencia (ej: `Perro` es-un `Animal`)

### 2. Sintaxis de Extensión

#### 2.1 Ejemplo en Java

```java
// Superclase
public class Animal {
    protected String nombre;

    public void comer() {
        System.out.println(nombre + " está comiendo");
    }
}

// Subclase que EXTIEÑE Animal
public class Perro extends Animal {
    private String raza;

    public void ladrar() {
        System.out.println("¡Guau!");
    }
}
```

#### 2.2 Ejemplo en Python

```python
class Animal:
    def __init__(self, nombre):
        self.nombre = nombre

    def comer(self):
        print(f"{self.nombre} está comiendo")

class Perro(Animal):  # Extiende Animal
    def __init__(self, nombre, raza):
        super().__init__(nombre)
        self.raza = raza

    def ladrar(self):
        print("¡Guau!")
```

### 4. Acceso y Visibilidad

#### 4.1 Modificadores de Acceso

| Modificador | Acceso en herencia        |
| ----------- | ------------------------- |
| `public`    | Total                     |
| `protected` | Solo en clase y subclases |
| `private`   | No accesible en subclases |

#### 4.2 Uso de `super`

Referencia a la superclase:

- Llamar al constructor de la superclase
- Acceder a métodos sobreescritos

```typescript
class Gato extends Animal {
  private vidas: number;

  constructor(nombre: string, vidas: number) {
    super(nombre); // Llama al constructor de Animal
    this.vidas = vidas;
  }

  maullar(): void {
    super.comer(); // Accede al método de la superclase
    console.log('¡Miau!');
  }
}
```

### 5. Sobreescritura de Métodos

#### 5.1 Principio de Sustitución (LSP)

Una subclase debe poder usarse en lugar de su superclase:

$$ \forall x \in \text{Superclase}, \forall y \in \text{Subclase} : y \text{ debe comportarse como } x $$

#### 5.2 Ejemplo de Overriding

```java
public class Animal {
    public void hacerSonido() {
        System.out.println("Sonido genérico");
    }
}

public class Gato extends Animal {
    @Override
    public void hacerSonido() {
        System.out.println("Miau");
    }
}
```
