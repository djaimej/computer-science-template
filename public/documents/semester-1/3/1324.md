### 1. Métodos y Parámetros

#### 1.1 Definiciones Clave

- **Método**: Función asociada a un objeto
- **Parámetro**: Variable en la declaración
- **Argumento**: Valor concreto pasado

**Fórmula de cohesión**:

$$ \text{Cohesión} \propto \frac{1}{\text{N° parámetros}} $$

#### 1.2 Ejemplo en Java

```java
public class Calculadora {
    // Método con parámetros
    public int sumar(int a, int b) { // a y b son parámetros
        return a + b;
    }
}

// Uso con argumentos
Calculadora calc = new Calculadora();
int resultado = calc.sumar(5, 3); // 5 y 3 son argumentos
```

#### 2.2 Lectura de Archivos (Java)

```java
import java.io.*;

public class Lector {
    public String leerArchivo(String ruta) throws IOException {
        StringBuilder contenido = new StringBuilder();
        try (BufferedReader br = new BufferedReader(new FileReader(ruta))) {
            String linea;
            while ((linea = br.readLine()) != null) {
                contenido.append(linea).append("\n");
            }
        }
        return contenido.toString();
    }
}
```

### 4. Manejo de Excepciones

#### 4.1 Try-With-Resources

```java
try (OutputStream os = new FileOutputStream("salida.txt")) {
    os.write("Datos".getBytes());
} catch (IOException e) {
    System.err.println("Error: " + e.getMessage());
}
```
