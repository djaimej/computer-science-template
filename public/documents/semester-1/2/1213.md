# Estructuras Discretas - Introducción

## 1.3 Introducción a los lenguajes formales: expresiones y mecanismos para su descripción (gramáticas y árboles de derivación).

---

### 1. Definición de Lenguajes Formales

Un **lenguaje formal** es un conjunto de cadenas de símbolos (palabras) construidas según reglas específicas sobre un **alfabeto** $(\Sigma)$.

- **Alfabeto $(\Sigma)$**: Conjunto finito de símbolos ( ej: $ \Sigma = \{a, b\} $ )
- **Cadena**: Secuencia finita de símbolos ( ej: $ w = "aabba" $ )
- **Lenguaje**: $ L \subseteq \Sigma^* $ (donde $ \Sigma^* $ es el conjunto de todas las cadenas posibles).

### 2. Gramáticas Formales

Una **gramática formal** es una tupla $ G = (V, \Sigma, P, S) $ donde:

- $V$: Variables no terminales
- $\Sigma$: Alfabeto (terminales)
- $P$: Reglas de producción ( ej: $A \rightarrow aB$ )
- $S$: Símbolo inicial ( $S \in V$ )

#### Ejemplo de Gramática:

```
G = (
   V = \{S, A\},
   Σ = \{a, b\},
   P = \{
      S → aA,
      A → bA | ε
   \},
   S = S
)
```

_Genera el lenguaje $ L = \{ab^n | n \geq 0\} $_

### 3. Tipos de Gramáticas (Jerarquía de Chomsky)

| Tipo | Restricciones         | Ejemplo               |
| ---- | --------------------- | --------------------- |
| 0    | Sin restricciones     | Máquinas de Turing    |
| 1    | Sensibles al contexto | $aSb \rightarrow acb$ |
| 2    | Libres de contexto    | $A \rightarrow aBc$   |
| 3    | Regulares             | $A \rightarrow aB$    |

### 4. Árboles de Derivación

Representación gráfica de cómo se deriva una cadena a partir del símbolo inicial.

**Ejemplo para la gramática anterior**:  
Derivación de $ "abb" $: S → aA → abA → abbA → abb

### 5. Expresiones Regulares

Notación compacta para describir lenguajes regulares:

- $a*$: 0 o más repeticiones de $a$
- $a|b$: $a$ ó $b$
- $(ab)^+$: 1 o más repeticiones de $"ab"$

**Ejemplo en código (Python)**:

```python
import re
patrón = re.compile(r'a(b*|c)')
print(patrón.fullmatch('abbb'))  # Coincide
```

### 6. Fórmulas Clave

- **Concatenación de lenguajes**: $L_1 \cdot L_2 = \{uv | u \in L_1, v \in L_2\}$
- **Estrella de Kleene**: $L^* = \bigcup_{i=0}^{\infty} L^i$
- **Longitud de cadena**: Si $w = a_1a_2...a_n$ entonces $|w| = n$
