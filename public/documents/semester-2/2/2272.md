# Estructuras de Datos - Pilas

## 7.2 Inserción, remoción y recuperación de elementos en una Pila.

---

### 1. Definición de Pila

Una **pila** es una estructura de datos lineal que sigue el principio **LIFO (Last In, First Out)**, es decir, el último elemento en entrar es el primero en salir.
Se puede imaginar como una pila de platos: solo puedes tomar o colocar el plato que está en la cima.

#### Características principales:

- Acceso a un solo extremo: la cima (top) de la pila.
- Operaciones básicas:

  - **Push**: Insertar un elemento en la cima.
  - **Pop**: Remover el elemento de la cima.
  - **Peek/Top**: Recuperar (sin remover) el elemento de la cima.

- Puede ser implementada con arreglos o listas enlazadas.

### 2. Operaciones en una Pila

#### 2.1 Inserción (Push)

**Definición:** Agregar un nuevo elemento a la cima de la pila.

**Notación formal:**

$$ push(S, x) \Rightarrow S' = S \cdot x $$

donde $S = (s_1, \ldots, s_k)$ es la secuencia de elementos, del fondo al tope, y $S \cdot x = (s_1, \ldots, s_k, x)$. No se usa la unión de conjuntos, $S \cup \{x\}$, porque una pila conserva el orden y puede tener elementos repetidos.

**Ejemplo en Python:**

```python
class Pila:
    def __init__(self):
        self.items = []

    def push(self, elemento):
        self.items.append(elemento)

p = Pila()
p.push(10)
p.push(20)
print(p.items)  # Salida: [10, 20]
```

#### 2.2 Remoción (Pop)

**Definición:** Eliminar el elemento que está en la cima de la pila y devolverlo.

**Notación formal:**

$$ pop(S) \Rightarrow x, S' \quad \text{donde } x \text{ es el elemento removido de la cima} $$

**Ejemplo en Python:**

```python
def pop(self):
    if self.items:
        return self.items.pop()
    else:
        return None

Pila.pop = pop   # se agrega como método de la clase Pila

p = Pila()
p.push(10)
p.push(20)
elemento = p.pop()
print(elemento)  # Salida: 20
print(p.items)   # Salida: [10]
```

#### 2.3 Recuperación (Peek / Top)

**Definición:** Obtener el elemento en la cima de la pila sin eliminarlo.

**Notación formal:**

$$ top(S) \Rightarrow x \quad \text{donde } x \text{ es el elemento de la cima} $$

**Ejemplo en Python:**

```python
def top(self):
    if self.items:
        return self.items[-1]
    else:
        return None

Pila.top = top

p = Pila()
p.push(10)
p.push(20)
print(p.top())  # Salida: 20
print(p.items)  # Salida: [10, 20]
```

### 3. Operaciones auxiliares

- **is\_empty()**: Verifica si la pila está vacía.
- **size()**: Retorna el número de elementos en la pila.

```python
def is_empty(self):
    return len(self.items) == 0

def size(self):
    return len(self.items)

Pila.is_empty = is_empty
Pila.size = size
```

### 4. Complejidad de las operaciones

| Operación | Complejidad |
| --------- | ----------- |
| push      | $O(1)$      |
| pop       | $O(1)$      |
| top       | $O(1)$      |
| is\_empty | $O(1)$      |
| size      | $O(1)$      |

> Todas las operaciones fundamentales de la pila son muy eficientes, lo que la hace ideal para algoritmos de retroceso (backtracking), evaluación de expresiones y manejo de llamadas de funciones.

### 5. Aplicaciones de las pilas

1. Evaluación de expresiones aritméticas (postfija y prefija).
2. Manejo de llamadas recursivas.
3. Navegación de historial (forward/backward).
4. Algoritmos de backtracking (laberintos, puzzles).
