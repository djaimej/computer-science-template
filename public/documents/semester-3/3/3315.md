## 1.5 Programación funcional.

---

La **programación funcional** es un paradigma de programación que trata la computación como la evaluación de funciones matemáticas y evita el cambio de estado y los datos mutables. Se enfoca en **qué** se debe hacer en lugar de **cómo** hacerlo.

#### Principios Fundamentales

- **Funciones puras**: Sin efectos secundarios y transparencia referencial
- **Inmutabilidad**: Los datos no se modifican después de su creación
- **Funciones de primera clase**: Las funciones pueden tratarse como cualquier otro valor
- **Evaluación perezosa**: Las expresiones se evalúan solo cuando se necesitan. Es característica de Haskell; la mayoría de los lenguajes funcionales, como Lisp, OCaml, Scala o Elixir, son estrictos por defecto y ofrecen la evaluación perezosa como opción.

### Bases Matemáticas: λ-Cálculo

La programación funcional se basa en el λ-cálculo, un sistema formal para expresar computación:

#### Expresiones Lambda

$$
(\lambda x. x + 1) \, 5 \rightarrow 5 + 1 \rightarrow 6
$$

En el λ-cálculo puro solo hay tres tipos de expresiones: variables $x,$ abstracciones $\lambda x. M$ (funciones anónimas) y aplicaciones $M \, N.$ Los números, los booleanos y la recursión se pueden codificar con ellas, y el sistema es tan poderoso como una máquina de Turing.

#### Funciones de Orden Superior

$$
map(f, [x_1, x_2, ..., x_n]) = [f(x_1), f(x_2), ..., f(x_n)]
$$

#### Reducción de Expresiones

$$
foldl(f, z, [x_1, x_2, ..., x_n]) = f(f(f(z, x_1), x_2), ..., x_n)
$$

### Conceptos Clave en Código

#### Funciones Puras

```python
# Función pura: mismo input → mismo output, sin efectos secundarios
def cuadrado(x):
    return x * x

# Función impura: tiene efecto secundario (modifica estado externo)
contador = 0
def incrementar_impuro():
    global contador
    contador += 1
    return contador
```

#### Inmutabilidad

```python
# Enfoque funcional: crear nuevas estructuras en lugar de modificar
def agregar_elemento(lista, elemento):
    return lista + [elemento]  # Nueva lista creada

# vs enfoque imperativo (modifica la original)
def agregar_elemento_imperativo(lista, elemento):
    lista.append(elemento)  # Modifica la lista original
    return lista
```

#### Funciones como Ciudadanos de Primera Clase

```python
# Las funciones pueden asignarse a variables
```

### Funciones de Orden Superior

#### Map

```python
# Aplica función a cada elemento
numeros = [1, 2, 3, 4, 5]
cuadrados = list(map(lambda x: x ** 2, numeros))
# [1, 4, 9, 16, 25]
```

#### Filter

```python
# Filtra elementos que cumplen condición
pares = list(filter(lambda x: x % 2 == 0, numeros))
# [2, 4]
```

#### Reduce

```python
from functools import reduce

# Reduce lista a un único valor
suma = reduce(lambda acc, x: acc + x, numeros, 0)
# 15
```

#### Composición de Funciones

```python
def compose(f, g):
    return lambda x: f(g(x))

doble = lambda x: x * 2
incrementar = lambda x: x + 1

doble_mas_uno = compose(doble, incrementar)
resultado = doble_mas_uno(5)  # (5 + 1) * 2 = 12
```

#### Ejemplo de Evaluación Perezosa

```python
# Generador perezoso en Python
def numeros_naturales():
    n = 0
    while True:
        yield n
        n += 1

# Solo calcula lo necesario
naturales = numeros_naturales()
primeros_5 = [next(naturales) for _ in range(5)]
# [0, 1, 2, 3, 4]
```

### Recursión y Tail Recursion

#### Recursión Simple

```python
def factorial(n):
    if n == 0:
        return 1
    else:
        return n * factorial(n - 1)

factorial(5)  # 120
```

#### Tail Recursion (Optimizable)

```python
def factorial_tail(n, acc=1):
    if n == 0:
        return acc
    else:
        return factorial_tail(n - 1, acc * n)

factorial_tail(5)  # 120
```

Una llamada es de **cola** si es lo último que hace la función, de modo que no queda trabajo pendiente: aquí se multiplica *antes* de llamar, en el acumulador. Lenguajes como Scheme, Haskell o Scala convierten la recursión de cola en un bucle y no consumen pila. **Python no hace esta optimización**: `factorial_tail(5000)` sigue provocando `RecursionError`, así que en Python conviene usar bucles o `reduce` para recorridos largos.

#### Recursión con Listas

```python
def longitud(lista):
    if not lista:
        return 0
    else:
        return 1 + longitud(lista[1:])

longitud([1, 2, 3, 4])  # 4
```

En Python, `lista[1:]` copia la lista en cada llamada, así que esta versión tarda $O(n^2).$ En los lenguajes funcionales las listas son enlazadas y tomar la cola cuesta $O(1).$

### Patrones Funcionales Comunes

#### Currying

```python
def curried_sumar(a):
    def sumar_b(b):
        return a + b
    return sumar_b

sumar_5 = curried_sumar(5)
```


#### Mónadas en Python (Option)

Una **mónada** es, de forma simplificada, un contenedor con una operación para encadenar cálculos (`flat_map`, llamado `>>=` o *bind* en Haskell) que se encarga de un efecto, aquí la posible ausencia de valor. Así se evita revisar `None` en cada paso.

```python
class Option:
    def __init__(self, value=None, is_empty=False):
        self.value = value
        self.is_empty = is_empty

    @staticmethod
    def some(value):
        return Option(value)

    @staticmethod
    def none():
        return Option(is_empty=True)

    def map(self, f):
        if self.is_empty:
            return Option.none()
        return Option.some(f(self.value))

    def flat_map(self, f):
        if self.is_empty:
            return Option.none()
        return f(self.value)

# Uso
resultado = Option.some(5).map(lambda x: x * 2).map(lambda x: x + 1)
print(resultado.value)                                  # 11

def dividir(a, b):
    return Option.none() if b == 0 else Option.some(a / b)

print(Option.some(10).flat_map(lambda x: dividir(x, 0)).map(lambda x: x + 1).is_empty)  # True
```

### Ventajas y Desventajas

#### Ventajas (✓)

- **Código más predecible**: Funciones puras sin efectos secundarios
- **Más fácil de testear**: Funciones aisladas y determinísticas
- **Mejor para concurrencia**: Sin estado compartido mutable
- **Código más expresivo**: Menos líneas para misma funcionalidad

#### Desventajas [X]

- **Curva de aprendizaje**: Diferente forma de pensar
- **Rendimiento**: Inmutabilidad puede crear overhead
- **Debugging complejo**: Stack traces profundos con recursión
- **Ecosistema limitado**: Menos librerías puras funcionales

### Aplicaciones Prácticas

#### Procesamiento de Datos

```python
from functools import reduce

# Procesamiento funcional de dataset
datos = [{'nombre': 'a', 'edad': 25}, {'nombre': 'b', 'edad': 30}]

# Pipeline funcional: se componen filter y map, sin modificar 'datos'
resultado = list(map(lambda x: x['nombre'].upper(),
                     filter(lambda x: x['edad'] > 25, datos)))
print(resultado)   # ['B']

# La misma idea con una función que encadena etapas
def tuberia(valor, *funciones):
    return reduce(lambda acc, f: f(acc), funciones, valor)

print(tuberia(datos,
              lambda ds: filter(lambda x: x['edad'] > 25, ds),
              lambda ds: map(lambda x: x['nombre'].upper(), ds),
              list))   # ['B']
```

Python no tiene un operador de tubería como `|>` de F# o Elixir; las listas por comprensión, `[x['nombre'].upper() for x in datos if x['edad'] > 25]`, son la forma más idiomática.

#### Web Development (Ejemplo Reactivo)

```python
# Patrón reactivo funcional
def crear_gestor_eventos():
    suscriptores = []

    def suscribir(callback):
        suscriptores.append(callback)

    def notificar(evento):
```

```python
from functools import reduce

# Ejercicio 1
def todos_cumplen(predicado, lista):
    return reduce(lambda acc, x: acc and predicado(x), lista, True)

def alguno_cumple(predicado, lista):
    return reduce(lambda acc, x: acc or predicado(x), lista, False)

def transformar_y_filtrar(transformacion, predicado, lista):
    return list(filter(predicado, map(transformacion, lista)))

def mi_map(f, xs):
    return [] if not xs else [f(xs[0])] + mi_map(f, xs[1:])

def mi_filter(p, xs):
    if not xs:
        return []
    resto = mi_filter(p, xs[1:])
    return [xs[0]] + resto if p(xs[0]) else resto

print(mi_map(lambda x: x + 1, [1, 2, 3]), mi_filter(lambda x: x % 2, [1, 2, 3]))   # [2, 3, 4] [1, 3]
```
