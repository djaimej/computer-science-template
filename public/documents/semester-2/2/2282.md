# Estructuras de Datos - Colas

## 8.2 Inserción, remoción y recuperación de elementos en una Cola.

---

### 1. Definición de Cola

Una **cola** es una estructura de datos lineal que sigue el principio **FIFO (First In, First Out)**, donde el primer elemento en entrar es el primero en salir. Se puede imaginar como una fila en un banco.

- **Frente (Front):** Elemento que será removido primero.
- **Final (Rear / Back):** Elemento que se inserta al final.

#### Características principales:

- Acceso a los elementos en ambos extremos de manera controlada.
- Operaciones básicas:
  - **Enqueue (encolar)**: Insertar un elemento al final de la cola.
  - **Dequeue (desencolar)**: Remover el elemento del frente de la cola.
  - **Front / Peek**: Recuperar el elemento al frente sin eliminarlo.
- Puede ser implementada mediante arreglos o listas enlazadas.

**Notación formal:**

$$ cola = [e_1, e_2, ..., e_n] $$
Donde $e_1$ es el primer elemento (frente) y $e_n$ es el último (final).

### 2. Operaciones en una Cola

#### 2.1 Inserción (Enqueue)

**Definición:** Agregar un elemento al final de la cola.

**Notación formal:**

$$ enqueue(cola, x) \Rightarrow cola' = cola \cup \{x\}_{final} $$

**Ejemplo en Python (Lista enlazada):**

```python
class Nodo:
    def __init__(self, valor):
        self.valor = valor
        self.siguiente = None

class Cola:
    def __init__(self):
        self.frente = None
        self.final = None

    def enqueue(self, valor):
        nodo = Nodo(valor)
        if self.final:
            self.final.siguiente = nodo
        self.final = nodo
        if not self.frente:
            self.frente = nodo

cola = Cola()
cola.enqueue(10)
cola.enqueue(20)
cola.enqueue(30)
```

**Diagrama Mermaid:**

```mermaid
    flowchart LR
    A[Frente: 10] --> B[20] --> C[30] --> D[Final]
```

#### 2.2 Remoción (Dequeue)

**Definición:** Eliminar el elemento del frente de la cola y devolverlo.

**Notación formal:**

$$ dequeue(cola) \Rightarrow x, cola' \quad \text{donde } x \text{ es el elemento del frente} $$

**Ejemplo en Python:**

```python
    def dequeue(self):
        if not self.frente:
            return None
        valor = self.frente.valor
        self.frente = self.frente.siguiente
        if not self.frente:
            self.final = None
        return valor

elemento = cola.dequeue()
print(elemento)  # Salida: 10
```

**Diagrama Mermaid:**

```mermaid
    flowchart LR
    A[Frente: 20] --> B[30] --> C[Final]
```

#### 2.3 Recuperación (Front / Peek)

**Definición:** Obtener el elemento al frente sin eliminarlo.

**Notación formal:**

$$ front(cola) \Rightarrow x \quad \text{donde } x \text{ es el elemento al frente} $$

**Ejemplo en Python:**

```python
    def front(self):
        if self.frente:
            return self.frente.valor
        return None

print(cola.front())  # Salida: 20
```

**Diagrama Mermaid:**

```mermaid
    flowchart LR
    A[Frente: 20] --> B[30] --> C[Final]
```

### 3. Operaciones auxiliares

- **is_empty():** Verifica si la cola está vacía.
- **size():** Retorna el número de elementos.

```python
    def is_empty(self):
        return self.frente is None

    def size(self):
        count = 0
        nodo = self.frente
        while nodo:
            count += 1
            nodo = nodo.siguiente
        return count
```

### 4. Complejidad de las operaciones

| Operación | Lista enlazada | Cola circular (arreglo)        |
| --------- | -------------- | ------------------------------ |
| enqueue   | O(1)           | O(1)                           |
| dequeue   | O(1)           | O(1)                           |
| front     | O(1)           | O(1)                           |
| is_empty  | O(1)           | O(1)                           |
| size      | O(n)           | O(1) (si se mantiene contador) |

### 5. Conclusiones

- Las operaciones básicas de la cola permiten **gestionar elementos en orden de llegada**.
- Tanto listas enlazadas como arreglos circulares permiten eficiencia en inserción y remoción.
- Recuperación de elementos y verificación de estado son operaciones rápidas y constantes.
