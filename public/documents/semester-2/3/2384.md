# Gráficas y Juegos - Juegos

## 8.4 Juegos bipersonales.

---

### Definición

Un **juego bipersonal** es un juego estratégico que involucra exactamente dos jugadores, donde cada jugador tiene un conjunto de estrategias disponibles y recibe un pago que depende de las estrategias elegidas por ambos jugadores.

### Representación Matemática

Un juego bipersonal se define como la tupla:

$$ G = (N, S_1, S_2, u_1, u_2) $$

Donde:

- $N = \{1, 2\}$: Conjunto de jugadores
- $S_i$: Conjunto de estrategias del jugador $i$
- $u_i: S_1 \times S_2 \rightarrow \mathbb{R}$: Función de utilidad del jugador $i$

### Forma Normal (Matricial)

Los juegos bipersonales de suma cero se representan mediante matrices de pagos:

#### Matriz de Pagos para Jugador 1

$$ A = \begin{bmatrix} u_1(s_1^1, s_2^1) & u_1(s_1^1, s_2^2) & \cdots & u_1(s_1^1, s_2^n) \\\ u_1(s_1^2, s_2^1) & u_1(s_1^2, s_2^2) & \cdots & u_1(s_1^2, s_2^n) \\\ \vdots & \vdots & \ddots & \vdots \\\ u_1(s_1^m, s_2^1) & u_1(s_1^m, s_2^2) & \cdots & u_1(s_1^m, s_2^n) \end{bmatrix} $$

### Tipos de Juegos Bipersonales

#### 1. Juegos de Suma Cero

$$ u_1(s_1, s_2) + u_2(s_1, s_2) = 0 \quad \forall s_1 \in S_1, s_2 \in S_2 $$

#### 2. Juegos de Suma Constante

$$ u_1(s_1, s_2) + u_2(s_1, s_2) = c \quad \forall s_1 \in S_1, s_2 \in S_2 $$

#### 3. Juegos de Suma Variable

Los pagos no suman una constante

### Ejemplo: Piedra, Papel o Tijeras

```
    Piedra-Piedra: [0, 0]
    Piedra-Papel: [-1, 1]
    Piedra-Tijeras: [1, -1]

    Papel-Piedra: [1, -1]
    Papel-Papel: [0, 0]

    Tijeras-Papel: [1, -1]
```

### Equilibrios en Juegos Bipersonales

#### Equilibrio de Nash

Un par de estrategias $ \left(s_1^* , s_2^* \right) $ es un equilibrio de Nash si:

$$ u_1 \left(s_1^* , s_2^* \right) \geq u_1 \left(s_1 , s_2^* \right) \quad \forall s_1 \in S_1 $$

$$ u_2 \left(s_1^* , s_2^* \right) \geq u_2 \left(s_1^* , s_2 \right) \quad \forall s_2 \in S_2 $$

#### Estrategias Dominadas

Una estrategia $s_i$ está estrictamente dominada si:

$$ \exists s_i' \in S_i \text{ tal que } u_i(s_i', s_{-i}) > u_i(s_i, s_{-i}) \quad \forall s_{-i} \in S_{-i} $$

### Implementación en Código

```typescript
// typescript

interface BimatrixGame {
  player1: {
    strategies: string[];
    payoffs: number[][];
  };
  player2: {
    strategies: string[];
    payoffs: number[][];
  };
}

class TwoPlayerGameSolver {
  // Encontrar equilibrios de Nash
  findNashEquilibria(game: BimatrixGame): StrategyPair[] {
    const equilibria: StrategyPair[] = [];

    for (let i = 0; i < game.player1.strategies.length; i++) {
      for (let j = 0; j < game.player2.strategies.length; j++) {
        if (this.isNashEquilibrium(game, i, j)) {
          equilibria.push({
            player1Strategy: game.player1.strategies[i],
            player2Strategy: game.player2.strategies[j],
            payoffs: [game.player1.payoffs[i][j], game.player2.payoffs[i][j]],
          });
        }
      }
    }
    return equilibria;
  }

  private isNashEquilibrium(game: BimatrixGame, i: number, j: number): boolean {
    // Verificar que jugador 1 no puede desviarse beneficiosamente
    const currentPayoff1 = game.player1.payoffs[i][j];
    for (let k = 0; k < game.player1.strategies.length; k++) {
      if (game.player1.payoffs[k][j] > currentPayoff1) {
        return false;
      }
    }

    // Verificar que jugador 2 no puede desviarse beneficiosamente
    const currentPayoff2 = game.player2.payoffs[i][j];
    for (let k = 0; k < game.player2.strategies.length; k++) {
      if (game.player2.payoffs[i][k] > currentPayoff2) {
        return false;
      }
    }

    return true;
  }
}
```

### Juegos de Suma Cero: Teorema Minimax

Para cualquier juego **finito** de suma cero de dos personas:

$$ \max_{x \in X} \min_{y \in Y} u_1(x, y) = \min_{y \in Y} \max_{x \in X} u_1(x, y) = v $$

Donde $X$ y $Y$ son los conjuntos de estrategias **mixtas** de cada jugador, $u_1(x, y)$ es el pago esperado del jugador 1 y $v$ es el **valor del juego**. Con estrategias puras la igualdad puede fallar: en piedra, papel o tijeras, el máximo de los mínimos en estrategias puras es $-1$ y el mínimo de los máximos es $1$, mientras que con estrategias mixtas ambos valen $v = 0$.

#### Algoritmo Minimax

```typescript
function minimax(game: ZeroSumGame, depth: number, isMaximizing: boolean): number {
  if (depth === 0 || game.isTerminal()) {
    return game.evaluate();
  }

  if (isMaximizing) {
    let maxEval = -Infinity;
    for (const move of game.getMoves()) {
      game.makeMove(move);
      const evaluation = minimax(game, depth - 1, false);
      game.undoMove(move);
      maxEval = Math.max(maxEval, evaluation);
    }
    return maxEval;
  } else {
    let minEval = Infinity;
    for (const move of game.getMoves()) {
      game.makeMove(move);
      const evaluation = minimax(game, depth - 1, true);
      game.undoMove(move);
      minEval = Math.min(minEval, evaluation);
    }
    return minEval;
  }
}
```

### Estrategias Mixtas

Cuando no hay equilibrio de Nash en estrategias puras:

#### Valor esperado para estrategias mixtas

$$ EU_1(\sigma_1, \sigma_2) = \sum_{s_1 \in S_1} \sum_{s_2 \in S_2} \sigma_1(s_1) \sigma_2(s_2) u_1(s_1, s_2) $$

#### Teorema de Nash

Todo juego finito tiene al menos un equilibrio de Nash en estrategias mixtas.

### Aplicaciones Prácticas

#### 1. Póker

#### 2. Negociaciones

### Fórmulas Importantes

#### Mejor respuesta del jugador $i$

$$ BR_i(s_{-i}) = \{s_i \in S_i : u_i(s_i, s_{-i}) \geq u_i(s_i', s_{-i}) \ \forall s_i' \in S_i\} $$

#### Estrategia mixta óptima

En un juego de suma cero, $\sigma_1$ es óptima para el jugador 1 si le garantiza al menos el valor $v$ contra cualquier estrategia pura del jugador 2:

$$ \sum_{s_1 \in S_1} \sigma_1(s_1) u_1(s_1, s_2) \geq v \quad \forall s_2 \in S_2 $$

$$ \sum_{s_1 \in S_1} \sigma_1(s_1) = 1, \qquad \sigma_1(s_1) \geq 0 $$

Maximizar $v$ sujeto a estas restricciones es un programa lineal. La desigualdad es una igualdad para las estrategias $s_2$ que el jugador 2 usa con probabilidad positiva en su estrategia óptima; si el jugador 2 las usa todas, se obtiene un sistema de ecuaciones.

### Herramientas de Análisis

- **Eliminación iterada de estrategias dominadas**
- **Búsqueda de equilibrios de Nash**
- **Cálculo de valores maximin y minimax**
- **Resolución de programas lineales** para estrategias mixtas
