# Álgebra Superior I - Sistemas de ecuaciones lineales

## 6.2 Criterios de Existencia de Soluciones

---

### **1. Teorema Fundamental: Rouché-Frobenius**

Un sistema de $m$ ecuaciones con $n$ incógnitas $A\mathbf{x} = \mathbf{b}$ tiene solución si y solo si:

$$ \text{rango}(A) = \text{rango}([A|\mathbf{b}]) $$

donde:

- $A$: Matriz de coeficientes ( $m \times n$ ),
- $[A|\mathbf{b}]$: Matriz aumentada ( $m \times (n+1)$ ).

**Corolario**:

- Si $\text{rango}(A) = n$: **Solución única** (sistema compatible determinado).
- Si $\text{rango}(A) < n$: **Infinitas soluciones** (sistema compatible indeterminado).
- Si $\text{rango}(A) \neq \text{rango}([A|\mathbf{b}])$: **Sin solución** (sistema incompatible).

### **2. Criterios Prácticos**

#### **2.1. Para Sistemas Cuadrados ( $m = n$ )**

- Si $\det(A) \neq 0$: Solución única (Regla de Cramer).
- Si $\det(A) = 0$:
  - $\text{rango}(A) = \text{rango}([A|\mathbf{b}]) \implies$ Infinitas soluciones.
  - $\text{rango}(A) \neq \text{rango}([A|\mathbf{b}]) \implies$ Sin solución.

**Ejemplo**:

Sistema:

$$ \begin{cases} x + 2y = 3 \\\ 2x + 4y = 6 \end{cases} $$

- $\det(A) = 0$ y $\text{rango}(A) = \text{rango}([A|\mathbf{b}]) = 1 \implies$ Infinitas soluciones ( $y = \frac{3 - x}{2}$ ).

#### **2.2. Para Sistemas No Cuadrados ( $m \neq n$ )**

- Calcular $\text{rango}(A)$ y $\text{rango}([A|\mathbf{b}])$ mediante eliminación gaussiana.

**Ejemplo**:

Sistema:

$$ \begin{cases} x + y + z = 2 \\\ 2x + 2y + 2z = 5 \end{cases} $$

- $\text{rango}(A) = 1$ y $\text{rango}([A|\mathbf{b}]) = 2 \implies$ Sin solución.

### **3. Interpretación Geométrica**

- **En $\mathbb{R}^2$**:
  - Dos rectas no paralelas: Solución única (punto de intersección).
  - Rectas coincidentes: Infinitas soluciones.
  - Rectas paralelas: Sin solución.

- **En $\mathbb{R}^3$**:
  - Planos que se cortan en una recta: Infinitas soluciones.
  - Planos paralelos: Sin solución.

### **4. Ejercicios Resueltos**

#### **Ejercicio 1**

Clasifique el sistema:

$$
\begin{cases} 3x - y = 1 \\\ 6x - 2y = 2 \end{cases}
$$

**Solución**:

- $\det(A) = 0$, $\text{rango}(A) = \text{rango}([A|\mathbf{b}]) = 1 \implies$ **Infinitas soluciones**.

#### **Ejercicio 2**

Determine para qué valor de $k$ el sistema es incompatible:

$$ \begin{cases} x + ky = 2 \\\ kx + y = 3 \end{cases} $$

**Solución**:

- $\det(A) = 1 - k^2 = 0 \implies k = \pm 1$.
  - Si $k = 1$: $\text{rango}(A) = 1 \neq \text{rango}([A|\mathbf{b}]) = 2 \implies$ **Sin solución**.
  - Si $k = -1$: Verificar $\text{rango}(A) = \text{rango}([A|\mathbf{b}]) = 1 \implies$ Infinitas soluciones.

### **5. Tabla Resumen**

| Condición                                                 | Tipo de Sistema          | Ejemplo                                                 |
| --------------------------------------------------------- | ------------------------ | ------------------------------------------------------- |
| $ \text{rango}(A) = \text{rango}([A \| \mathbf{b}]) = n $ | Compatible determinado   | $ \begin{cases} x + y = 2 \\\ x - y = 0 \end{cases} $   |
| $ \text{rango}(A) = \text{rango}([A \| \mathbf{b}]) < n $ | Compatible indeterminado | $ \begin{cases} x + y = 2 \\\ 2x + 2y = 4 \end{cases} $ |
| $ \text{rango}(A) \neq \text{rango}([A \| \mathbf{b}]) $  | Incompatible             | $ \begin{cases} x + y = 2 \\\ x + y = 3 \end{cases} $   |

### **6. Ejercicios Propuestos**

1. Clasifique el sistema:

$$ \begin{cases} 2x - y = 3 \\\ -4x + 2y = -6 \end{cases} $$

2. Encuentre $k$ para que el sistema tenga solución única:

$$ \begin{cases} x + 2y = 1 \\\ 3x + ky = 2 \end{cases} $$

**Solución al ejercicio 1**:

- $\det(A) = 0$, $\text{rango}(A) = \text{rango}([A|\mathbf{b}]) = 1 \implies$ **Infinitas soluciones**.
