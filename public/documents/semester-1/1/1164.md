# Álgebra Superior I - Sistemas de ecuaciones lineales

## 6.4 Espacio de Soluciones de un Sistema No Homogéneo

---

### **1. Definición y Estructura General**

Para un sistema no homogéneo $ A\mathbf{x} = \mathbf{b} $ ( $\mathbf{b} \neq \mathbf{0}$ ), el **espacio de soluciones** tiene la forma:

$$ \mathbf{x} = \mathbf{x}_p + \mathbf{x}_h, $$

donde:

- $\mathbf{x}_p$: **Solución particular** ( cualquier solución que satisface $A\mathbf{x}_p = \mathbf{b}$ ).
- $\mathbf{x}_h$: **Solución general del sistema homogéneo asociado** ( $A\mathbf{x}_h = \mathbf{0}$ ).

**Teorema**: Si $S$ es el conjunto solución de $A\mathbf{x} = \mathbf{b}$ y $S_0$ es el espacio solución de $A\mathbf{x} = \mathbf{0}$, entonces:

$$ S = \mathbf{x}_p + S_0. $$

### **2. Pasos para Encontrar el Espacio de Soluciones**

1. **Resolver el sistema homogéneo asociado** $A\mathbf{x} = \mathbf{0}$:
   - Encontrar una base $\{\mathbf{v}_1, \dots, \mathbf{v}_k\}$ de $S_0$ ( donde $k = n - \text{rango}(A)$ ).

2. **Encontrar una solución particular** $\mathbf{x}_p$ de $A\mathbf{x} = \mathbf{b}$:
   - Usar eliminación gaussiana o sustitución directa.

3. **Escribir la solución general**:
   $$
   \mathbf{x} = \mathbf{x}_p + c_1 \mathbf{v}_1 + \dots + c_k \mathbf{v}_k, \quad c_i \in \mathbb{R}.
   $$

### **3. Ejemplo Completo**

**Sistema no homogéneo**:

$$ \begin{cases} x + 2y - z = 3 \\\ 2x + y + z = 4 \end{cases} $$

#### **Paso 1: Sistema homogéneo asociado**

$$ \begin{cases} x + 2y - z = 0 \\\ 2x + y + z = 0 \end{cases} $$

- **Solución**:
  - Eliminación gaussiana:

$$ \begin{pmatrix} 1 & 2 & -1 \\\ 2 & 1 & 1 \end{pmatrix} \xrightarrow{F_2 \rightarrow F_2 - 2F_1} \begin{pmatrix} 1 & 2 & -1 \\\ 0 & -3 & 3 \end{pmatrix} $$

- Soluciones: $z = t$, $y = t$, $x = -t \implies \mathbf{x}_h = t \begin{pmatrix} -1 \\\ 1 \\\ 1 \end{pmatrix}$.

#### **Paso 2: Solución particular**

- Asignamos $z = 0$ y resolvemos:

$$ \begin{cases} x + 2y = 3 \\\ 2x + y = 4 \end{cases} \implies x = 1, \, y = 1 \implies \mathbf{x}_p = \begin{pmatrix} 1 \\\ 1 \\\ 0 \end{pmatrix}. $$

#### **Paso 3: Solución general**

$$ \mathbf{x} = \begin{pmatrix} 1 \\\ 1 \\\ 0 \end{pmatrix} + t \begin{pmatrix} -1 \\\ 1 \\\ 1 \end{pmatrix}, \quad t \in \mathbb{R}. $$

### **4. Interpretación Geométrica**

- **En $\mathbb{R}^3$**:
  - Si $S_0$ es una recta (dimensión 1), $S$ es una recta paralela desplazada por $\mathbf{x}_p$.
  - Si $S_0$ es un plano (dimensión 2), $S$ es un plano paralelo.

**Ejemplo**:  
Para el sistema anterior, $S_0$ es la recta generada por $(-1, 1, 1)$ y $S$ es la recta paralela que pasa por $(1, 1, 0)$.

### **5. Teorema de Rouché-Frobenius Revisitado**

El sistema $A\mathbf{x} = \mathbf{b}$ tiene solución si y solo si $\text{rango}(A) = \text{rango}([A|\mathbf{b}])$.

- **Caso compatible**: La dimensión del espacio solución es $n - \text{rango}(A)$.

### **6. Ejercicios Propuestos**

1. Encuentre el espacio de soluciones para:

$$ \begin{cases} 2x - y + z = 1 \\\ x + y - z = 2 \end{cases} $$

2. Demuestre que si $\mathbf{x}_p$ y $\mathbf{x}_p'$ son soluciones particulares, entonces $\mathbf{x}_p - \mathbf{x}_p'$ es solución del sistema homogéneo.

**Solución al ejercicio 1**:

- **Solución homogénea**: $\mathbf{x}_h = t \begin{pmatrix} 0 \\\ 1 \\\ 1 \end{pmatrix}$.
- **Solución particular**: $\mathbf{x}_p = \begin{pmatrix} 1 \\\ 1 \\\ 0 \end{pmatrix}$.
- **Solución general**: $\mathbf{x} = \begin{pmatrix} 1 \\\ 1 \\\ 0 \end{pmatrix} + t \begin{pmatrix} 0 \\\ 1 \\\ 1 \end{pmatrix}$.

### **Resumen Visual**

| Concepto               | Fórmula/Estructura            | Ejemplo                                                                                        |
| ---------------------- | ----------------------------- | ---------------------------------------------------------------------------------------------- |
| **Solución general**   | $\mathbf{x}_p + \mathbf{x}_h$ | $\begin{pmatrix} 1 \\\ 1 \\\ 0 \end{pmatrix} + t \begin{pmatrix} -1 \\\ 1 \\\ 1 \end{pmatrix}$ |
| **Dimensión de $S_0$** | $n - \text{rango}(A)$         | $3 - 2 = 1$ (recta)                                                                            |
