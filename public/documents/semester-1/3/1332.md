# Introducción a las Ciencias de la Computación - Objetos, estados y servicios

## 3.2 Expresiones y cadenas.

---

Una **expresión** es un fragmento de código que se evalúa para producir un valor: `precio * cantidad`, `edad >= 18`, `nombre.length()`. Los métodos de un objeto están hechos casi por completo de expresiones, así que conocer con precisión cómo se evalúan, en qué orden y con qué tipo de resultado, evita muchos errores sutiles. Las **cadenas** de caracteres merecen atención aparte: son el tipo de dato más usado para comunicarse con el usuario y en Java tienen reglas propias.

### 1. Expresiones y tipos

Toda expresión tiene un **tipo**, que el compilador determina antes de ejecutar:

| Expresión               | Tipo      | Valor            |
| ----------------------- | --------- | ---------------- |
| `7 / 2`                 | `int`     | `3`              |
| `7 / 2.0`               | `double`  | `3.5`            |
| `7 % 2`                 | `int`     | `1`              |
| `-7 / 2`                | `int`     | `-3`             |
| `-7 % 2`                | `int`     | `-1`             |
| `'a' + 1`               | `int`     | `98`             |
| `"a" + 1`               | `String`  | `"a1"`           |
| `3 > 2 && 2 > 1`        | `boolean` | `true`           |

**División entera.** Si ambos operandos son enteros, la división descarta la parte fraccionaria, **truncando hacia cero**. El operador `%` da el residuo, con el signo del dividendo. Calcular un promedio como `suma / n` con dos enteros es un error clásico: hay que convertir uno de ellos a `double`.

### 2. Precedencia y asociatividad

Cuando una expresión tiene varios operadores, se evalúan según su **precedencia**, de mayor a menor:

| Nivel | Operadores                         | Asociatividad      |
| ----- | ---------------------------------- | ------------------ |
| 1     | `x++` `x--` llamadas a métodos `.` | izquierda          |
| 2     | `++x` `--x` `-x` `!` conversión `(tipo)` | derecha      |
| 3     | `*` `/` `%`                        | izquierda          |
| 4     | `+` `-`                            | izquierda          |
| 5     | `<` `<=` `>` `>=` `instanceof`     | izquierda          |
| 6     | `==` `!=`                          | izquierda          |
| 7     | `&&`                               | izquierda          |
| 8     | `\|\|`                             | izquierda          |
| 9     | `? :`                              | derecha            |
| 10    | `=` `+=` `-=` `*=` …               | derecha            |

Así, `a + b * c` es `a + (b * c)`, y `10 - 4 - 3` es `(10 - 4) - 3 = 3` por la asociatividad izquierda. Ante la duda, los paréntesis hacen explícita la intención y no cuestan nada.

**Evaluación en cortocircuito.** En `a && b`, si `a` es falso ya no se evalúa `b`; en `a || b`, si `a` es verdadero tampoco. Esto permite escribir condiciones seguras como `x != 0 && 10 / x > 2`, que nunca divide entre cero.

**Operador condicional.** `condicion ? valor1 : valor2` es una expresión que vale `valor1` si la condición es verdadera y `valor2` si no: `String estado = calificacion >= 6 ? "aprobado" : "reprobado";`.

**Asignación compuesta e incremento.** `x += 5` equivale a `x = x + 5`. `x++` incrementa `x` pero, como expresión, vale el valor **anterior**; `++x` vale el nuevo. Usarlos dentro de expresiones más grandes vuelve el código difícil de leer, así que conviene usarlos solos.

### 3. Conversiones de tipo

**Conversión de ensanchamiento.** Java convierte automáticamente un tipo a otro más amplio sin pérdida de información: `int` a `long`, `int` a `double`. En `7 / 2.0`, el 7 se convierte a `7.0` antes de dividir.

**Conversión de estrechamiento.** Pasar a un tipo más pequeño puede perder información y exige una conversión explícita, o *cast*:

```java
double promedio = 8.97;
int truncado = (int) promedio;            // 8: se descarta la parte decimal
long redondeado = Math.round(promedio);    // 9
int grande = 300;
byte b = (byte) grande;                    // 44: se conservan los 8 bits menos significativos
double prom = (double) 7 / 2;              // 3.5: se convierte el 7 antes de dividir
double malo = (double) (7 / 2);            // 3.0: la división entera ya ocurrió
```

### 4. Cadenas en Java

Una cadena es un objeto de la clase `String` que representa una sucesión de caracteres Unicode. Los literales se escriben entre comillas dobles, y algunos caracteres se escriben con **secuencias de escape**: `\n` salto de línea, `\t` tabulador, `\"` comillas, `\\` diagonal invertida.

**Inmutabilidad.** Un `String` **nunca cambia**. Los métodos que parecen modificarlo, como `toUpperCase` o `replace`, regresan una cadena **nueva** y dejan intacta la original:

```java
String s = "hola";
s.toUpperCase();          // crea "HOLA" pero no se guarda en ninguna parte
System.out.println(s);    // hola
s = s.toUpperCase();      // ahora s se refiere a la nueva cadena
System.out.println(s);    // HOLA
```

La inmutabilidad hace que las cadenas puedan compartirse con seguridad entre partes del programa y entre hilos.

**Métodos más usados:**

| Método                      | Ejemplo                                     | Resultado            |
| --------------------------- | ------------------------------------------- | -------------------- |
| `length()`                  | `"computadora".length()`                    | `11`                 |
| `charAt(i)`                 | `"computadora".charAt(0)`                   | `'c'`                |
| `substring(i, j)`           | `"computadora".substring(3, 6)`             | `"put"`              |
| `indexOf(s)`                | `"computadora".indexOf("ta")`               | `5`                  |
| `contains(s)`               | `"computadora".contains("dora")`            | `true`               |
| `toUpperCase()`             | `"Hola".toUpperCase()`                      | `"HOLA"`             |
| `trim()`, `strip()`         | `"  hola  ".strip()`                        | `"hola"`             |
| `replace(a, b)`             | `"a-b-c".replace("-", "/")`                 | `"a/b/c"`            |
| `split(regex)`              | `"a,b,c".split(",")`                        | `["a", "b", "c"]`    |
| `equals(s)`                 | `"Hola".equals("hola")`                     | `false`              |
| `equalsIgnoreCase(s)`       | `"Hola".equalsIgnoreCase("hola")`           | `true`               |
| `compareTo(s)`              | `"ana".compareTo("beto")`                   | un número negativo   |
| `String.join(sep, ...)`     | `String.join("-", "a", "b")`                | `"a-b"`              |
| `repeat(n)`                 | `"ab".repeat(3)`                            | `"ababab"`           |

Los índices empiezan en 0, y en `substring(i, j)` el índice `j` **no** se incluye.

### 5. Comparar cadenas: `equals` y no `==`

El operador `==` aplicado a objetos compara **referencias**: si las dos variables apuntan al mismo objeto. Para comparar el **contenido** de dos cadenas se usa `equals`:

```java
String a = "hola";
String b = new String("hola");
System.out.println(a == b);         // false: son objetos distintos
System.out.println(a.equals(b));    // true: tienen los mismos caracteres
```

A veces `==` parece funcionar con literales, porque Java reutiliza los literales iguales, pero con cadenas leídas del teclado o construidas durante la ejecución falla. La regla es simple: **las cadenas se comparan con `equals`**. Para ordenarlas alfabéticamente se usa `compareTo`, que regresa un número negativo, cero o positivo.

### 6. Construir cadenas: `StringBuilder`

Como cada concatenación con `+` crea una cadena nueva, construir una cadena larga en un ciclo con `+` copia una y otra vez los caracteres anteriores. Para eso existe `StringBuilder`, una secuencia de caracteres **modificable**:

```java
StringBuilder sb = new StringBuilder();
for (int i = 1; i <= 5; i++) {
    sb.append(i).append(i < 5 ? ", " : "");
}
String lista = sb.toString();       // "1, 2, 3, 4, 5"
String alReves = new StringBuilder("roma").reverse().toString();   // "amor"
```

### 8. Ejemplo integrador: palíndromos

Un palíndromo se lee igual al derecho y al revés, ignorando espacios, mayúsculas y acentos:

```java
import java.text.Normalizer;

public class Palindromos {
    static String limpiar(String texto) {
        String sinAcentos = Normalizer.normalize(texto, Normalizer.Form.NFD)
                                      .replaceAll("\\p{M}", "");   // quita las marcas diacríticas
        return sinAcentos.toLowerCase().replaceAll("[^a-z0-9ñ]", "");
    }

    static boolean esPalindromo(String texto) {
        String t = limpiar(texto);
        int i = 0, j = t.length() - 1;
        while (i < j) {
            if (t.charAt(i) != t.charAt(j)) return false;
            i++;
            j--;
        }
        return true;
    }

    public static void main(String[] args) {
        System.out.println(esPalindromo("Anita lava la tina"));          // true
        System.out.println(esPalindromo("Dábale arroz a la zorra el abad"));  // true
        System.out.println(esPalindromo("Computadora"));                 // false
    }
}
```

> **Conexión con CC.** El procesamiento de texto es una parte enorme del software: validar entradas, analizar archivos de configuración, buscar en documentos. Las expresiones regulares que acepta `split` o `replaceAll` son las de Estructuras Discretas (subtema 1.3), y los compiladores empiezan su trabajo dividiendo el código fuente, que es una cadena, en componentes.
