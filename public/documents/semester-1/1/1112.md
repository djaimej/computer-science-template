# Álgebra Superior I - Conjuntos

## 1.2 Operaciones con conjuntos: unión, intersección, complemento y diferencia.

---

A partir de los conjuntos básicos y la relación de subconjunto estudiados en el subtema 1.1, es posible construir nuevos conjuntos mediante operaciones. Estas operaciones —unión, intersección, complemento y diferencia— son el equivalente conjuntista de las operaciones aritméticas, y sus leyes algebraicas (en particular las leyes de De Morgan) son fundamentales en el diseño de circuitos digitales, la optimización de consultas en bases de datos y la lógica proposicional.

### 1. Unión

La **unión** de dos conjuntos $A$ y $B$ es el conjunto de todos los elementos que pertenecen a $A$, a $B$ o a ambos.

$$A \cup B = \{x \mid x \in A \lor x \in B\}$$

**Ejemplo:** Si $A = \{1, 2, 3\}$ y $B = \{3, 4, 5\}$, entonces $A \cup B = \{1, 2, 3, 4, 5\}$.

**Propiedades:**

| Propiedad   | Enunciado                               |
| ----------- | --------------------------------------- |
| Conmutativa | $A \cup B = B \cup A$                   |
| Asociativa  | $(A \cup B) \cup C = A \cup (B \cup C)$ |
| Idempotente | $A \cup A = A$                          |
| Neutro      | $A \cup \varnothing = A$                |
| Absorbente  | $A \cup U = U$                          |

### 2. Intersección

La **intersección** de $A$ y $B$ es el conjunto de todos los elementos comunes a ambos.

$$A \cap B = \{x \mid x \in A \land x \in B\}$$

**Ejemplo:** Con $A = \{1, 2, 3\}$ y $B = \{3, 4, 5\}$: $A \cap B = \{3\}$.

Cuando $A \cap B = \varnothing$, los conjuntos se denominan **disjuntos**.

**Propiedades:**

| Propiedad   | Enunciado                               |
| ----------- | --------------------------------------- |
| Conmutativa | $A \cap B = B \cap A$                   |
| Asociativa  | $(A \cap B) \cap C = A \cap (B \cap C)$ |
| Idempotente | $A \cap A = A$                          |
| Neutro      | $A \cap U = A$                          |
| Absorbente  | $A \cap \varnothing = \varnothing$      |

### 3. Complemento

Dado el conjunto universal $U$, el **complemento** de $A$ es el conjunto de los elementos de $U$ que no pertenecen a $A$.

$$A^c = \bar{A} = U \setminus A = \{x \in U \mid x \notin A\}$$

**Ejemplo:** Si $U = \{1, 2, 3, 4, 5\}$ y $A = \{1, 2\}$, entonces $A^c = \{3, 4, 5\}$.

**Propiedades:**

- **Involución:** $(A^c)^c = A$
- **Complemento del universal:** $U^c = \varnothing$ y $\varnothing^c = U$
- **Ley del complemento:** $A \cup A^c = U$ y $A \cap A^c = \varnothing$

### 4. Diferencia

La **diferencia** $A \setminus B$ ( también escrita $ A - B $ ) es el conjunto de los elementos de $A$ que no pertenecen a $B$.

$$A \setminus B = \{x \mid x \in A \land x \notin B\}$$

**Ejemplo:** $\{1,2,3\} \setminus \{3,4,5\} = \{1,2\}$.

**Observación:** La diferencia no es conmutativa. En general $A \setminus B \neq B \setminus A$.

Relación con el complemento:

$$ A \setminus B = A \cap B^c $$

#### 4.1 Diferencia simétrica

La **diferencia simétrica** $A \triangle B$ contiene los elementos que pertenecen a exactamente uno de los dos conjuntos:

$$A \triangle B = (A \setminus B) \cup (B \setminus A) = (A \cup B) \setminus (A \cap B)$$

**Ejemplo:** $\{1,2,3\} \triangle \{3,4,5\} = \{1,2,4,5\}$.

> **Conexión con CC.** La diferencia simétrica corresponde a la operación XOR bit a bit en enteros. Si $A$ y $B$ son los conjuntos de bits que valen 1 en dos enteros, entonces $A \triangle B$ da el conjunto de bits en $1$ del XOR de ambos.

### 5. Leyes de De Morgan

Las leyes de De Morgan relacionan el complemento con la unión y la intersección:

$$\overline{A \cup B} = \bar{A} \cap \bar{B}$$
$$\overline{A \cap B} = \bar{A} \cup \bar{B}$$

**Demostración de la primera ley:**

Sea $x \in \overline{A \cup B}$. Entonces $x \notin A \cup B$, lo que significa que $x \notin A$ y $x \notin B$, es decir, $x \in \bar{A}$ y $x \in \bar{B}$, por lo que $x \in \bar{A} \cap \bar{B}$. La contención $\bar{A} \cap \bar{B} \subseteq \overline{A \cup B}$ se demuestra de manera análoga. $\square$

> **Importancia.** En lógica proposicional, las leyes de De Morgan afirman $\lnot(p \lor q) \equiv \lnot p \land \lnot q$ y $\lnot(p \land q) \equiv \lnot p \lor \lnot q$. En Estructuras Discretas (subtema 2.1) se estudia esta dualidad formal.

### 6. Propiedades distributivas

$$A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$$
$$A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$$

**Ejemplo de la segunda:**

- $A = \{1,2\}$, $B = \{2,3\}$, $C = \{3,4\}$
- $B \cup C = \{2,3,4\}$, por lo que $A \cap (B \cup C) = \{2\}$
- $(A \cap B) = \{2\}$, $(A \cap C) = \varnothing$, por lo que $(A \cap B) \cup (A \cap C) = \{2\}$ ✓

### 7. Ejemplo integrador

Sean $U = \{1,2,3,4,5,6,7,8\}$, $A = \{1,2,3,4\}$, $B = \{3,4,5,6\}$.

| Operación              | Resultado                      |
| ---------------------- | ------------------------------ |
| $A \cup B$             | $\{1,2,3,4,5,6\}$              |
| $A \cap B$             | $\{3,4\}$                      |
| $A \setminus B$        | $\{1,2\}$                      |
| $B \setminus A$        | $\{5,6\}$                      |
| $A \triangle B$        | $\{1,2,5,6\}$                  |
| $\bar{A}$              | $\{5,6,7,8\}$                  |
| $\overline{A \cup B}$  | $\{7,8\}$                      |
| $\bar{A} \cap \bar{B}$ | $\{7,8\}$ (verifica De Morgan) |

4. **Código Python.** El siguiente código implementa las operaciones. Ejecútalo y verifica los resultados del ejemplo integrador:

```python
U = {1,2,3,4,5,6,7,8}
```
