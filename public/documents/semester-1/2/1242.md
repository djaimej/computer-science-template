# Estructuras Discretas - Relaciones

## 4.2 Relaciones binarias: propiedades (reflexividad, simetría, transitividad, etc.), representación mediante matrices y digráficas.

---

### 1. Definición Formal

Una **relación binaria** $R$ sobre un conjunto $A$ es un subconjunto del producto cartesiano:

$$ R \subseteq A \times A $$

**Notación**: $(a,b) \in R$ o $aRb$

### 2. Propiedades Fundamentales

| Propiedad         | Definición Matemática                        | Ejemplo                | Contraejemplo          |
| ----------------- | -------------------------------------------- | ---------------------- | ---------------------- |
| **Reflexiva**     | $\forall a \in A, (a,a) \in R$               | $\leq$ en $\mathbb{N}$ | $<$ en $\mathbb{N}$    |
| **Simétrica**     | $(a,b) \in R \Rightarrow (b,a) \in R$        | Igualdad $(=)$         | Divisibilidad $(\|)$   |
| **Transitiva**    | $(a,b), (b,c) \in R \Rightarrow (a,c) \in R$ | $<$ en $\mathbb{R}$    | Relación "padre de"    |
| **Antisimétrica** | $(a,b), (b,a) \in R \Rightarrow a = b$       | $\subseteq$            | $\leq$ en $\mathbb{Z}$ |
| **Irreflexiva**   | $\forall a \in A, (a,a) \notin R$            | $<$ en $\mathbb{N}$    | $\leq$ en $\mathbb{Q}$ |

### 3. Representación Matricial

Para $A = \{a_1, ..., a_n\}$, la **matriz de adyacencia** $M_R$ es:

$$ M_R[i][j] = \begin{cases} 1 & \text{si } (a_i, a_j) \in R \\\ 0 & \text{en otro caso} \end{cases} $$

**Ejemplo en Python**:

```python
# Representación de R = {(1,1), (1,2), (2,3)} en A = {1,2,3}
M_R = [
    [1, 1, 0],
    [0, 0, 1],
    [0, 0, 0]
]
```

**Propiedades en matrices**:

- Reflexiva: Diagonal principal con 1's
- Simétrica: Matriz simétrica ( $M = M^T$ )
- Transitiva: $M^2 \leq M$ (donde $\leq$ es por elementos)

### 4. Representación como Digráfica

Un **grafo dirigido** $G = (V, E)$ donde:

- $V = A$ (vértices)
- $E = R$ (aristas dirigidas)

### 5. Operaciones con Matrices

- **Unión**: $M_{R \cup S} = M_R \lor M_S$ (OR lógico)
- **Intersección**: $M_{R \cap S} = M_R \land M_S$ (AND lógico)
- **Composición**: $M_{R \circ S} = M_R \cdot M_S$ (producto matricial)

### 6. Teorema Fundamental

Para una relación transitiva $R$:  
$$ R \text{ es transitiva} \iff R^2 \subseteq R $$  
donde $R^2 = R \circ R$

### 7. Aplicación Práctica

**Algoritmo de Warshall** para clausura transitiva:

```python
def warshall(M):
    n = len(M)
    for k in range(n):
        for i in range(n):
            for j in range(n):
                M[i][j] = M[i][j] or (M[i][k] and M[k][j])
    return M
```
