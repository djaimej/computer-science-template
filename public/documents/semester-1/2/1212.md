# Estructuras Discretas - Introducción

## 1.2 Panorama de las matemáticas discretas.

---

Las **matemáticas discretas** son un área de las matemáticas que estudia estructuras cuyos elementos son distintos y separados (no continuos). Se enfoca en objetos contables y es fundamental en ciencias de la computación, ingeniería y lógica matemática.

### Áreas Principales

1. **Teoría de Conjuntos**
   - Estudio de colecciones de objetos (elementos).
   - Operaciones básicas: unión $(A \cup B)$, intersección $(A \cap B)$, complemento $(A^c)$.

2. **Lógica Matemática**
   - Proposiciones y conectivos lógicos: $\land$ (AND), $\lor$ (OR), $\neg$ (NOT).
   - Ejemplo:  
     $(p \land q) \rightarrow r$ (Si p AND q, entonces r).

3. **Teoría de Grafos**
   - Grafos $G = (V, E)$ donde $V$ = vértices, $E$ = aristas.
   - Ejemplo en código:

```python
  grafo = {
      'A': ['B', 'C'],
      'B': ['A', 'D'],
      'C': ['A'],
      'D': ['B']
  }
```

4. **Combinatoria**
   - Conteo de estructuras discretas: permutaciones $(n!)$, combinaciones $(C(n, k) = \frac{n!}{k!(n-k)!})$.

5. **Relaciones y Funciones**
   - Relaciones binarias: subconjuntos de $A \times B$.
   - Propiedades: reflexividad, simetría, transitividad.

### Ejemplos Clave

- **Conjuntos**:

```python
  A = {1, 2, 3}
  B = {3, 4, 5}
  print(A.intersection(B))  # Salida: {3}
```

- **Permutaciones**:  
  Número de formas de ordenar 3 elementos: $3! = 6$.

- **Lógica**:  
  Tabla de verdad para $p \lor q$:

  | p   | q   | $p \lor q$ |
  | --- | --- | ---------- |
  | V   | V   | V          |
  | V   | F   | V          |
  | F   | V   | V          |
  | F   | F   | F          |

### Fórmulas Destacadas

1. **Principio del Palomar**:  
   Si $n+1$ objetos se distribuyen en $n$ cajas, al menos una caja contiene más de un objeto.

2. **Número de subconjuntos de un conjunto**:  
   Para un conjunto con $n$ elementos: $2^n$ subconjuntos posibles.

3. **Coeficiente binomial**:

$$ C(n, k) = \binom{n}{k} = \frac{n!}{k!(n-k)!} $$

### Aplicaciones

- **Algoritmos**: Análisis de complejidad ( notación $O(n)$ ).
- **Criptografía**: Aritmética modular $(a \equiv b \pmod{m})$.
- **Bases de datos**: Teoría de relaciones (álgebra relacional).
