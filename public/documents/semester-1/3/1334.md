## 3.4 Distintos tipos de métodos: constructores, de acceso, de actualización, de implementación y auxiliares.

---

### 1. Clasificación de Métodos

#### 1.1 Taxonomía Fundamental

$$ \text{Métodos} = \left\lbrace \begin{array}{ll} \text{Constructores} & \text{Inicialización} \\\ \text{Acceso} & \text{Consulta} \\\ \text{Actualización} & \text{Modificación} \\\ \text{Implementación} & \text{Lógica central} \\\ \text{Auxiliares} & \text{Soporte interno} \end{array} \right\rbrace $$

### 2. Tipos de Métodos

#### 2.1 Constructores

Inicializan el estado del objeto al crearse.

**Ejemplo Java:**

```java
public class CuentaBancaria {
    private double saldo;

    // Constructor
    public CuentaBancaria(double saldoInicial) {
        this.saldo = saldoInicial;
    }
}
```

#### 2.2 Métodos de Acceso (Getters)

Obtienen valores sin modificar el estado.

```typescript
class Persona {
  private _edad: number;

  get edad(): number {
    return this._edad;
  }
}
```

#### 2.3 Métodos de Actualización (Setters)

Modifican el estado controladamente.

```python
class Sensor:
    def __init__(self):
        self._valor = 0

    def set_valor(self, nuevo_valor):
        if 0 <= nuevo_valor <= 100:
            self._valor = nuevo_valor
```

#### 2.4 Métodos de Implementación

Contienen la lógica principal.

```java
public class Calculadora {
    public double calcularIVA(double monto) {
        return monto * 0.16; // Lógica central
    }
}
```

#### 2.5 Métodos Auxiliares

Soportan internamente a otros métodos.

```typescript
class PasswordValidator {
  private _esSegura(texto: string): boolean {
    return texto.length >= 8;
  }
}
```

### 4. Buenas Prácticas

#### 4.1 Regla de Ocultamiento

$$ \text{Encapsulamiento} = \frac{\text{Métodos públicos}}{\text{Métodos totales}} \leq 0.3 $$

#### 4.2 Principios Clave

1. **Constructores**: Validar parámetros esenciales
2. **Getters/Setters**: Usar para atributos críticos
3. **Auxiliares**: Siempre privados
