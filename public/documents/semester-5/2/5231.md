## 3.1 El fenómeno de los mundos pequeños.

---

El fenómeno de los mundos pequeños es una propiedad fundamental en las redes complejas que describe la paradoja de que, a pesar de su tamaño masivo, la mayoría de las redes reales (sociales, biológicas, tecnológicas) presentan caminos cortos entre cualquier par de nodos. Este concepto fue popularizado por el experimento de Stanley Milgram en 1967, que demostró que dos personas cualesquiera en los Estados Unidos estaban conectadas por una cadena de aproximadamente seis conocidos, dando origen al término "seis grados de separación".

### Definiciones Fundamentales

**Red de Mundo Pequeño**: Una red que combina dos propiedades clave:

1. Alto coeficiente de agrupamiento (clustering coefficient)
2. Corta distancia promedio entre nodos (short average path length)

**Coeficiente de Agrupamiento Local**: Para un nodo $i$ con $k_i$ vecinos, el coeficiente de agrupamiento $C_i$ mide la proporción de conexiones existentes entre los vecinos de $i$ respecto al total posible:

$$C_i = \frac{2e_i}{k_i(k_i - 1)}$$

donde $e_i$ es el número de aristas entre los $k_i$ vecinos del nodo $i$.

**Coeficiente de Agrupamiento Global**: Promedio de todos los coeficientes de agrupamiento locales:

$$C = \frac{1}{n} \sum_{i=1}^{n} C_i$$

**Distancia Promedio**: La longitud promedio del camino más corto entre todos los pares de nodos:

$$L = \frac{1}{n(n-1)} \sum_{i \neq j} d(i,j)$$

donde $d(i,j)$ es la distancia (número de aristas) entre los nodos $i$ y $j$.

### Modelo de Watts-Strogatz

El modelo de Watts-Strogatz (1998) proporciona un mecanismo para generar redes con propiedades de mundo pequeño. El algoritmo consta de tres pasos:

1. Crear una red regular unidimensional con $n$ nodos, cada uno conectado a sus $k$ vecinos más cercanos ( $k/2$ a cada lado )
2. Reesconectar cada arista con probabilidad $p$, moviendo un extremo a un nodo aleatorio
3. El resultado es una interpolación entre regularidad $(p = 0)$ y aleatoriedad $(p = 1)$

```python
import networkx as nx
import matplotlib.pyplot as plt
import numpy as np

def watts_strogatz_simulation(n, k, p):
    """
    Simula el modelo de Watts-Strogatz y calcula propiedades clave
    """
    # Crear gráfico según el modelo
    G = nx.watts_strogatz_graph(n, k, p)

    # Calcular propiedades
    avg_clustering = nx.average_clustering(G)
    avg_path_length = nx.average_shortest_path_length(G)

    return G, avg_clustering, avg_path_length

# Ejemplo de uso
n = 100  # número de nodos
k = 6    # grado medio
p = 0.1  # probabilidad de reconexión

G, C, L = watts_strogatz_simulation(n, k, p)
print(f"Coeficiente de agrupamiento: {C:.4f}")
print(f"Distancia promedio: {L:.4f}")
```

### Propiedades Emergentes

Las redes de mundo pequeño exhiben varias propiedades importantes:

1. **Robustza y Fragilidad**: Son robustas a fallos aleatorios pero frágiles ante ataques dirigidos a nodos centrales
2. **Difusión Rápida de Información**: La información se propaga rápidamente debido a los caminos cortos
3. **Comunidad y Globalidad**: Combinan estructura local (comunidades) con conectividad global

### Ejemplo Práctico: Red Social

Consideremos una red social donde:

- 1000 personas (nodos)
- Cada persona conoce en promedio a 50 otras (grado medio)
- La probabilidad de reconexión es p = 0.05

En esta red:

- El coeficiente de agrupamiento será alto (amigos de amigos tienden a conocerse)
- La distancia promedio será baja (cualquier par de personas está conectado por pocos intermediarios)

### Implementación Avanzada

```python
import networkx as nx
import matplotlib.pyplot as plt
import numpy as np

class MundoPequenoAnalizer:
    def __init__(self, n, k):
        self.n = n
        self.k = k

    def analizar_propiedades(self, p_values):
        """Analiza cómo varían las propiedades con diferentes p"""
        C_values = []
        L_values = []

        for p in p_values:
            G = nx.watts_strogatz_graph(self.n, self.k, p)
            C_values.append(nx.average_clustering(G))
            L_values.append(nx.average_shortest_path_length(G))

        return C_values, L_values

    def visualizar_transicion(self, p_values, C_values, L_values):
        """Visualiza la transición de mundo pequeño"""
        fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 5))

        # Coeficiente de agrupamiento normalizado
        C0 = C_values[0]
        ax1.plot(p_values, [C/C0 for C in C_values], 'o-')
        ax1.set_xscale('log')
        ax1.set_xlabel('Probabilidad de reconexión (p)')
        ax1.set_ylabel('C(p)/C(0)')
        ax1.set_title('Coeficiente de Agrupamiento')
        ax1.grid(True)

        # Distancia promedio normalizada
        L0 = L_values[0]
        ax2.plot(p_values, [L/L0 for L in L_values], 's-')
        ax2.set_xscale('log')
        ax2.set_xlabel('Probabilidad de reconexión (p)')
        ax2.set_ylabel('L(p)/L(0)')
        ax2.set_title('Distancia Promedio')
        ax2.grid(True)

        plt.tight_layout()
        plt.show()

# Uso del analizador
analizador = MundoPequenoAnalizer(n=100, k=6)
p_values = np.logspace(-4, 0, 20)
C_values, L_values = analizador.analizar_propiedades(p_values)
analizador.visualizar_transicion(p_values, C_values, L_values)
```

### Aplicaciones en Computación Distribuida

En sistemas distribuidos, las propiedades de mundo pequeño tienen implicancias importantes:

1. **Routing Eficiente**: Algoritmos de routing que aprovechan la estructura de mundo pequeño
2. **Búsqueda Descentralizada**: Estrategias de búsqueda que utilizan información local para encontrar caminos globales
3. **Difusión de Información**: Protocolos eficientes para propagar información en la red
